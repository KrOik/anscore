## 手动离线调用

先进入表中对应的包目录。四包均以**包目录**为 files.f 和 example/files.f 的
相对路径基准，不能进入 example/ 后直接复用清单。核心清单只闭合核心；示例
清单还包含实际组合所需依赖。复制交付时保留 cores/ 下这些相对路径，不能只
复制单个新 RTL 文件。完整端口/错误/复位约定以各包 README 为准，当前执行
状态以各包 QUALIFICATION/DELIVERY 为准。

下面是静态 elaboration 调用形状，供新的独立使用环境选择；本轮集成文档没有
执行这些命令，也不授权覆盖已有 once guard、原回执或镜像。

```text
iverilog -g2012 -tnull -s signed8_codebook_search -f files.f
iverilog -g2012 -tnull -s codebook_residual_encode -f example/files.f

iverilog -g2012 -tnull -s price_time_order_matcher -f files.f
iverilog -g2012 -tnull -s two_client_limit_matcher -f example/files.f

iverilog -g2012 -tnull -s fft_overlap_save_fir -f files.f
iverilog -g2012 -tnull -s real_fft_overlap_save_fir -f example/files.f

iverilog -g2012 -tnull -s multistop_linear_gradient -f files.f
iverilog -g2012 -tnull -s linear_gradient_porter_duff -f example/files.f
```

每对命令分别在其包目录使用。工具名称是调用示意，原资格只绑定原计划中
固定的本机可执行文件/参数/环境，不扩张为任意 Icarus 或综合工具兼容证明。

## signed8_codebook_search

[契约](../cores/acceleration/signed8_codebook_search/README.md) ·
[资格](../cores/acceleration/signed8_codebook_search/QUALIFICATION.md) ·
[交付](../cores/acceleration/signed8_codebook_search/DELIVERY.md)

MAX_CODES1..64、MAX_DIMS1..256、TAG_W1..32，默认16/16/8。同步高复位、
普通 ready/valid。cfg 逐分量装载有序码字前缀；c 命令捕获实际码字/维数，s
输入 signed8 查询；先消费 m 摘要，再消费 r 重建/残差。最低索引解决距离平局，
最大精确平方距离16646400，signed9 残差覆盖±255。重配截短立即使旧后缀失效，
请求缺少完整前缀时拒绝且不接收查询数据。

核心无外部 RTL 依赖；示例连接已有 canonical
`cores/acceleration/int4_weight_matvec/rtl/deps/stream_requantize.v`。示例捕获
每个命令的 residual shift，输出 signed8 RNE/饱和编码与 clip/inexact；旧编码
尾部可能与新查询重叠，tag/index/LAST及已捕获 shift保持各自归属。四次实际
仿真包括1×1、3×5、64×256核心和16×16示例。无训练/量化尺度选择/模型
准确率保证；margin是距离差，不能解释为概率。

## price_time_order_matcher

[契约](../cores/acceleration/price_time_order_matcher/README.md) ·
[资格](../cores/acceleration/price_time_order_matcher/QUALIFICATION.md) ·
[交付](../cores/acceleration/price_time_order_matcher/DELIVERY.md)

ORDERS1..32，PRICE_W/QTY_W/TAG_W各1..32，默认16/32/32/8；ID固定unsigned64。
价格/数量为精确整数 ticks/lots。rst_n异步低有效，必须跨上升沿并同步释放；
复用 hash 的复位清理期间不接受命令。c_op为 NEW_LIMIT、CANCEL_ID、GET_ID、
CLEAR。f先按maker价格、价格优先/同价FIFO逐成交输出，全部成交退休后给r最终
回复；该回复退休前核心不接受下一命令。所有输出在背压下稳定。

依赖原样 `ram_hash_table` 和 `cip_sync_sp_ram`，见包内依赖证明。真实双客户端
示例提供轮询仲裁；成交共用f流/f_ready并由f_client标识归属，完成通过a/b_r_valid
分别返回。有限检查为ORDERS1/5/32三个核心配置及
ORDERS8示例；最大有31-maker扫单。NEW必须在成交前保留一个既有空槽，即使
立即可成交也可能FULL拒绝。无原子改单、市场/IOC、风控、自成交防护、持久
日志、会话恢复或交易场所认证。复位取消当前账簿epoch，不撤销外部已接受成交。

## fft_overlap_save_fir

[契约](../cores/signal_processing/fft_overlap_save_fir/README.md) ·
[资格](../cores/signal_processing/fft_overlap_save_fir/QUALIFICATION.md) ·
[交付](../cores/signal_processing/fft_overlap_save_fir/DELIVERY.md)

LOG_N1..8（N2..256）、DATA_W8..24、TAG_W1..32，默认6/16/8。同步高复位。
g/k装载M个复数系数，g_taps1..N、g_frac0..DATA_W-1；r成功回复退休时原子
发布并清历史。c命令捕获输入数、
end/restart及tag，s提供实际样本，m给样本或终止标记。普通命令输入B=N-M+1项；
end命令输入0..B项，自动补零并输出剩余FIR尾部。M1无历史/尾部，MN的B=1。
输出LAST后可能仍在内部排空补零结果，应等待c_ready。

完整离线依赖只有原样 `cores/acceleration/stream_fft/rtl/stream_fft.sv`，其中
ROM已内嵌；基线没有该文件，本轮显式新增支持源，不引入旧FFT manifest或
任何历史验证。接受数值是非缩放系数/数据FFT、完整复乘后按coefficient fraction
做RNE/饱和、逐级二分缩放IFFT的整数链，具有累计overflow/inexact；不能直接
等同理想卷积。实际实数适配器公开虚部残差，不将量化误差隐藏为零。

有限检查为N2/W8/T1、N8/W12/T8、N256/W24/T32及N64/W16/T8实数示例。
完整MN尾部只在N2/N8/N64闭环；N256 MN全尾明确未测。内部FFT故障未注入。
两个共享实乘法算子、四块复数N-word RAM是源码预算；串行变换/乘法不能承诺
持续每拍一采样。没有Fmax、物理DSP/BRAM数、目标器件fit或功耗结论。

## multistop_linear_gradient

[契约](../cores/image_processing/multistop_linear_gradient/README.md) ·
[资格](../cores/image_processing/multistop_linear_gradient/QUALIFICATION.md) ·
[交付](../cores/image_processing/multistop_linear_gradient/DELIVERY.md)

MAX_STOPS1..16、TAG_W1..32，默认16/8；端点/样点为signed18 Q10.8，destination
x/y16是另行转发的元数据。同步高复位、普通ready/valid。c管理BEGIN/PUBLISH/
INVALIDATE，t顺序加载停靠点，s输入实际二维点，m输出premultiplied RGBA。
核心自己计算点积投影与精确分母，不要求host预选t或插值区间。PAD/REPEAT/
REFLECT支持负边界；重合端点、重复停靠点、单停靠点均有明确规则；只在最终
RGBA字节处RNE。BEGIN立即使旧表失效，完整有效装载后PUBLISH才能启用。

离线核心依赖既有serial multiply、integer_divider及同步RAM；实际示例再加入
原样rgba_porter_duff。成功资格来自独立followup01的三个核心和两个真实组合
配置，涵盖13种Porter-Duff模式。原首次EOF检查失败及其镜像保留；仅复制TB
修复，原向量复用，没有自动重跑或改生产RTL。颜色空间由调用者约定；没有
gamma/直通alpha自动转换、完整SVG/CSS、显示接口或帧缓存系统资格。
