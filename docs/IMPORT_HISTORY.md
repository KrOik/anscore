# Source import history

This repository imports reusable FPGA IP sources from a local development
workspace. The existing GitHub LICENSE commit is retained unchanged.

At the maintainer's request, source import commits use scheduled author and
committer dates from 2026-09-20 through 2026-10-15, in UTC+08:00. These are
backfilled import dates, not contemporaneous development or validation dates.
The import was prepared on 2026-10-15. No daily engineering activity is implied.

There are 20 commits per calendar day across that range: 519 nonempty source
import commits plus the original LICENSE commit dated 2026-10-15. Each import
commit adds a named group of source, test, model, fixture or documentation files.
Intermediate import commits are partial snapshots; validation applies to the
complete imported source tree rather than every partial snapshot.

Publication excludes historical run evidence, implementation netlists, capture
data, executable simulation output, logs, machine connection settings and local
progress records. Necessary reference vectors and expected test results remain
source inputs. Original development snapshots remain local.

The import preserves the existing remote main history and uses a regular
fast-forward push. It does not publish the prior local export commit containing
historical run artifacts.
