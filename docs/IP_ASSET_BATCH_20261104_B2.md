## 接口和资源边界

四项均为同一时钟域、同步高有效复位、标准ready/valid、无CE接口。
复位取消在途事务和未消费结果。现有CE-qualified stream需要先作语义适配。
详细位宽、顺序、配置、延迟、错误与存储契约以各包README为准。

- 完成缓冲的tag是可复用槽位索引，不含generation。调用者必须保证一次有效完成，
  并在复位时协调取消；已退休并重新分配后的迟到旧完成不能被该接口区分。
  它提供有序退休，不是完整AXI乱序或跨时钟基础设施。默认载荷存储392bit，
  默认结构风险LOW、最大参数MEDIUM；已完成的头部退休间隔为2拍。
- 2×2求解器以共享迭代乘除换取固定存储，不并行展开矩阵逆运算。
  非奇异定点解向零截断，输出超范围饱和；奇异报告无唯一解，不判断无解或多解。
  默认结构风险LOW、最大宽度MEDIUM。
- 最大矩形只存列高和单调栈，使用O(WIDTH)存储；它找内部全1的矩形，
  与连通域外接框不同。固定像素数决定帧长，SOF/EOL错误只标记，不改变调度。
  默认数组1280bit，存储风险LOW、算术和RAM推断MEDIUM。
- 稀疏行核的精确和仅包含前MAX_TERMS个所选项中合法索引的乘积。
  非法索引仍占前缀名额且贡献零；`m_overflow`表示容量截断，不是算术溢出。
  向量只能在行间重载，在途重载请求不会阻塞当前行。默认向量存储1024bit，
  存储风险LOW、算术映射MEDIUM。

以上资源标签来自结构审查，没有实测面积、DSP/BRAM占用、频率或功耗承诺。
所有本批内核为 **LINT_PASS + UNIT_SIM_PASS + HW_UNVERIFIED**，示例为
**INTEGRATION_CANDIDATE**。未执行综合、布局布线、STA、上板或完整回归，
未将既有硬件证据沿用到新RTL。最大参数只编译的范围均在对应README中说明。

## 累计稳定源码集合

[累计清单](snapshots/source_20261104_b2.json)包含两批八项能力：本批四项，
以及前批选择性多播、CDF 5/3整数小波、块SSIM和在线堆队列。
清单记录69个包内文本文件、各功能提交、源文件依赖、示例顶层与有限证据。
所有交付源码均为独立原创Apache-2.0；固定外部参考、许可与未采用候选的原因
见包内SOURCES/README。稀疏矩阵候选仅检索到元数据，后续读取失败，未引入源码。
仓库根LICENSE随完整稳定Git快照保留；离线编译不依赖联网或外部构建系统。

功能提交完成后，本批进入仅处理完整性、依赖、命名、接口与索引的冻结窗口。
[源码快照检查器](../scripts/check_source_snapshot.py)从固定Git内容读取清单文件，
核对包内摘要、原始有限检查记录及其源码哈希，检查依赖闭包和包间模块重名，
然后只将清单文件导出到隔离临时目录。八个内核和八个示例已在同一次Icarus
`-tnull`编译中通过，未借用工作区未提交文件。记录见
[冻结检查输出](snapshots/source_20261104_b2_check.txt)。

复查累计稳定快照：

```text
python -B scripts/check_source_snapshot.py --ref snapshot/source-20261104-b2 --manifest docs/snapshots/source_20261104_b2.json --compile
```

检查器验证交付一致性和独立编译，不重新运行数值仿真，也不扩张既有测试的证明范围。
原始有限单元测试可按每包README独立重放。检查器新增的声明式证据规则已检查
有效记录接收，以及缺完成标记、无关工具失败、缺记录和NOT_RUN状态拒绝。
旧快照格式仍可使用；上一批固定标签不移动。
