## 离线调用边界

保留 cores/ 中的原始相对目录和依赖；不能只复制新核文件。
Winograd 的 files.f 从包目录解析，example/files.f 从其 example/ 目录解析。
其他三包的 files.f 和 example/files.f 均从各自包目录解析。
调用前阅读对应 README 的端口、位宽、参数、配置和复位约定。
这些入口不授权再次调用本轮已消耗的 once runner 或覆盖报告、镜像。

Winograd 处理单输入通道4×4 tile，按输出核行产生2×2结果；它不是整帧 CNN
前端或多通道累加器。实际组合复用原有 stream_requantize，提供 RNE、zero
point 和 S8 饱和。修复后的离线模型在 followup01/model/reference.py；原模型
作为失败证据保留。减少 tile 乘法次数不构成面积、频率或功耗改善证据。

回放核消费已经有序的时间戳流；第一条记录建立锚点，停顿时虚拟时间仍推进，
pause 冻结时钟。显式 epoch_flush 可以取消 held 输出，上下游必须共同遵守。
组合使用现有 dual_itch_time_merge；源错误使该 epoch poisoned，需共享复位。
该组合不生成 watermark/EOS 承诺，也不保证缺失事件自行超时。

相位拟合核输出精确有理数 I/Q 的分子、分母及 Gram 诊断，消费者负责除法。
它不搜索频率、不输出幅相，也不把近奇异窗口标为安全；仅检测精确秩亏。
已有 CORDIC 和串行乘法器保持原样，组合复位桥有单独释放约定。
实际内层观察结果保留，但整套20秒门禁未通过，应作为受限候选使用。

抠像核使用 RGB opponent 平面的平方距离生成连续 alpha，提供 green/blue
去溢色和精确 /255 预乘。实际 source-over 组合对背景和元数据保持同步。
正常无停顿时核15级、组合18级，II1；这些是结构和有限 TB 见证，不是 FPGA
布线时钟或视频分辨率保证。模块没有帧缓存、CDC 或外部存储依赖。
