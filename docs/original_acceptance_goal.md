## 4. 统一接口与复位

### Stream

- 所有主数据接口使用 `tdata/tvalid/tready`；仅在上升沿 `tvalid && tready` 时发生传输。
- 图像附加 `tuser=SOF`、`tlast=EOL`，与当前像素绑定；气泡、反压、流水线延迟不得错位。
- `tvalid && !tready` 时数据、valid 和全部边带稳定；不丢失、重复或乱序。
- 源端 valid 不依赖下游先拉高 ready；状态只在握手或明确内部事务条件下推进。
- 说明弹性缓冲、停顿传播、缓冲容量和 ready 路径；避免长组合 ready 链。
- 配置使用独立握手接口，定义原子提交、生效边界、忙时行为及非法参数错误。多字段更新不得出现混合配置。

### 时钟/复位

- 普通算法核单时钟 `clk`，`rst_n` 低有效同步复位，无门控时钟或异步反馈。
- 复位清 valid、控制及必要算法状态；不通过清空大 RAM 破坏 BRAM 推断。未初始化 RAM 不得成为有效输出。
- 异步 Stream FIFO 是双时钟例外：分别定义 `s_clk/m_clk` 及复位合同、Gray 指针、同步器和约束。
- 明确是否支持单侧复位；不支持时规定协调复位及重新开放握手流程。复位丢弃在途事务的范围必须有文档和测试。
- CDC 结构和时序审查独立于仿真/板测；不能以采集正常证明不存在亚稳态风险。

## 5. 数值、吞吐与资源合同

- DSP 明确总位宽、符号位、分数位及 Q 记法；每个节点推导数值范围和保护位。
- 保留足够宽中间结果，在规定量化边界舍入/截断并饱和，不允许意外溢出回绕。不要机械地在每次加乘后饱和而损失精度。
- 明确负数舍入及半值规则；NCO 相位等有意模运算单独说明，不误判为数值错误。
- 图像默认 8/10-bit 无符号；卷积、梯度和 CSC 内部用充分位宽及必要的有符号运算。
- 递归滤波说明稳定性、量化误差、极限环及动态系数更新的状态保留/清除行为。提供系数合法性检查，不承诺任意系数稳定。
- 参数有显式支持范围：尺寸、L/M、tap 数、SOS 数、模板长度、标签和区域容量；非法配置被拒绝或输出错误，不静默运行。
- 等速逐样本算法以 II=1 为目标；重采样、缩放、DDC/DUC 按真实输入/输出速率关系定义握手和缓存，不能承诺物理上不可能的双向每拍满速。
- IIR 反馈、CCA 合并等先证明吞吐；资源与吞吐冲突时提出配置选项，未经接受的功能削减不算完成原需求。
- 每核注明无反压延迟、II、启动填充、尾部排空、持续运行条件；反压下区分有效推进和墙钟周期。
- 分别报告核心、wrapper、组合链 LUT/FF/DSP/BRAM；综合和 P&R 口径不能混用。估算仅用于规划，验收使用实际报告。

## 6. 全部资产清单

每项建立需求—配置—实现—仿真—构建—板测证据映射，可共享基础模块，但不得遗漏功能。

### DSP

1. **多相重采样**：整数插值/抽取、有理 L/M；抗混叠/抗镜像系数生成；相位、样本计数、尾部处理及速率合同。
2. **Biquad/SOS**：DF-II Transposed、级联、动态系数原子更新、状态策略、定点稳定性及饱和。
3. **DDC/DUC**：复数混频、NCO/DDS、CIC、FIR 抽插链；复用已有核，验证整链增益、频谱和速率。
4. **幅值/功率/RMS/峰值**：滑动/分块、阈值、动态缩放；定义开方精度、窗口、峰值位置及并列规则。
5. **频谱前后处理**：Hann/Hamming/Blackman、复数模平方、平均、峰值搜索；定义频点顺序、窗增益及幅度标定。
6. **相关/匹配滤波**：实数/复数、模板配置、共轭与相关方向、位置输出、块尾处理。
7. **AGC**：线性/对数增益控制、能量估计、攻击/释放、静音、动态范围与限幅。
8. **DPLL/载波和定时恢复**：分别定义载波环和定时环、输入信号模型、鉴相/误差检测器、环路滤波、捕获范围及锁定条件。不能以相位累加器冒充完整恢复链。缺调制/采样率规格时提出具体参考配置，并标明验证范围。
9. **DC 去除与基线跟踪**：一阶 DC blocker、滑动均值去除、慢变基线估计；定义启动瞬态、截止频率、复位及稳态误差。
10. **半带与 CIC 补偿滤波**：半带 2 倍抽插、零系数/对称系数优化、CIC 通带补偿；复用 FIR/CIC，交付独立配置工具和通带纹波/阻带衰减测试。
11. **分数延时 / Farrow 插值**：可配置小数延时、三次插值参考配置、延时动态更新；验证群延时、幅频误差和变化连续性。异步采样率转换还需速率估计和缓冲控制，不由 Farrow 单核替代。
12. **Hilbert / 解析信号与包络**：Hilbert FIR、实虚支路延迟对齐、包络与瞬时相位/频率；定义有效频带、零幅值行为及相位展开规则。
13. **Goertzel / 单多频检测**：可配置频点、块长、窗函数、功率及检测阈值；与独立 DFT 比较，规定状态增长位及块尾计算时间。
14. **STFT / Welch 功率谱**：分帧、重叠缓冲、窗、FFT 调用、功率谱平均；复用已有 FFT，明确频率轴、单双边谱、PSD 归一化、帧步长和带宽预算。
15. **自适应 LMS/NLMS**：可配置 tap、步长、更新使能和系数读回；NLMS 定义能量下限及除法精度，验证收敛、失配、饱和和定点极限行为。
16. **PFB 信道化器**：多相 FIR＋FFT、通道排序、抽取率和通道增益；先实现资源可容纳的小通道配置，验证通道隔离、混叠、帧对齐及持续吞吐。

第 9–14 项作为常用补充资产；第 15–16 项为进阶批次，仍纳入需求追踪。与已有核重合的算法通过复用和组合交付，不重复计算资产收益。

### ISP

1. **CSC**：RGB↔YCbCr、RGB→灰度；BT.601/709、Full/Limited、通道顺序和色度中点。
2. **2D 卷积**：3×3/5×5 可配置核、补零/复制边界、行缓存、缩放及排空。
3. **中值**：3×3/5×5 排序网络，说明比较器规模、流水线及相等值行为。
4. **Sobel/Scharr**：Gx/Gy、幅值、方向、阈值；定义 CORDIC/开方或近似模式及误差，L1 不称为精确欧氏幅值。
5. **形态学**：腐蚀/膨胀/开/闭，可配置结构元素；定义二值/灰度模式与边界值。
6. **ROI/缩放**：裁剪、最近邻、双线性；坐标映射、像素中心、边界、输出尺寸及速率。
7. **Bayer**：RGGB/BGGR/GRBG/GBRG 双线性恢复；帧原点、ROI 后 Bayer 相位和边界。
8. **基础 ISP**：BLC、白平衡增益、DPC、Gamma LUT。区分外部白平衡增益应用与自动 AWB 估计；自动估计需定义算法/统计/更新时刻。DPC 定义检测、替换及坏点簇限制。
9. **CCA**：4/8 连通、标签等价合并、面积、质心、包围盒；明确缓存、帧后处理、连续帧和标签/区域溢出。依据资源选择两遍或流式，不预设无条件 II=1。
10. **积分图 / 局部统计 / 自适应阈值**：积分和及平方和、局部均值/方差、均值自适应阈值；明确累加位宽、窗口面积、边界和输出尺寸，复用滑窗或前缀和基础。
11. **直方图均衡 / CLAHE**：复用直方图，补 CDF、映射 LUT、分块裁剪与块间插值；明确常量图、余数重分配、当前帧/前帧统计策略及帧缓存需求。
12. **AE/AWB/AF 统计**：分区亮度、通道和、过曝计数、对焦梯度能量；独立输出统计接口。AE 控制先提供曝光/增益建议及离线场景测试，真实相机闭环需相机接口证据，不能由统计核冒充闭环验收。
13. **镜头阴影校正 LSC**：分通道网格增益及双线性插值、Bayer 相位保持、增益钳位；包含网格生成/导入工具与边角误差测试。
14. **色彩校正矩阵 CCM / 色调映射**：可配置 3×3 有符号矩阵、偏置、单调分段线性/LUT 色调曲线；复用 CSC 算术基础，分别定义线性光/编码域及更新边界。
15. **色度重采样与像素打包**：4:4:4↔4:2:2↔4:2:0、平面/交织格式、8/10-bit 打包；定义色度采样位置、滤波、奇数尺寸策略及各分量速率，不能仅丢样声称完成抗混叠转换。
16. **Canny 边缘链**：高斯平滑、梯度、方向量化、非极大值抑制、双阈值和滞后连接；复用卷积/梯度，精确滞后连接需处理全图连通及存储，局部近似另列模式和误差。
17. **帧差 / 背景建模**：绝对帧差、阈值、运行均值背景及运动掩码；定义帧存、背景更新、场景突变恢复和连续帧带宽。
18. **保边降噪**：先实现 3×3 双边滤波参考配置，使用距离/强度差 LUT；验证权重归一化、边缘保持、噪声抑制、零分母保护及 LUT 误差。
19. **几何重映射**：翻转、90°旋转、仿射/透视、镜头畸变映射；共享坐标发生器、双线性采样和帧缓存访问层。明确越界填充、除法精度、乱序存储访问及带宽，不承诺所有变换仅靠行缓存完成。

第 10–15 项优先补齐常用 ISP 能力；第 16–19 项为进阶批次。需整帧存储的配置先做容量和带宽预算，使用目标板已验证的外存接口或明确有界的小图配置；小图板测结果不能推广为任意分辨率实时处理。

## 7. 多 subagent 协作

主 agent 维护能力矩阵、共享接口、依赖图、集成顺序、验收配置和中央台账，负责唯一板卡调度及最终复核。子 agent 独占任务目录，交付 RTL/模型/测试/文档及真实日志，不越界修改共享模块。

按环境可用槽位并行，不要求为每个核常驻一个 agent。先完成共享 Stream/窗口合同与测试，再并行 DSP 和 ISP 算法；构建可按资源并行，烧录/采集严格串行。共享脚本、顶层和中央台账由主 agent 顺序集成。每次集成按影响运行必要回归。

首批建议：基础 Stream/窗口；DSP Biquad、重采样、统计、DC 去除与频谱前后处理；ISP CSC、3×3 卷积/中值/Sobel/形态学。第二批补齐常用扩展：半带/CIC 补偿、Farrow、Hilbert、Goertzel、STFT/Welch，以及局部统计、均衡、ISP 统计、LSC/CCM、色度格式。结合依赖推进 5×5、缩放/Bayer、相关/AGC/DDC/DUC；资源和存储方案确定后推进 LMS/PFB、恢复环、CCA/Canny、时域降噪与几何变换。全部纳入总范围，按模块逐项验收。

## 9. 验收 SOP

### A. 规格、基线与模型

先定合法输入、参数和输出合同。修复先复现原版错误；新增先建立参考模型。保留旧 golden；参考模型不得读取 DUT 输出生成预期。浮点证明算法和误差，bit-exact 检查逐值定点行为，两者不可互相替代。

### B. 仿真

- 数值：极值、零、脉冲、常量、随机、算法专用向量及适用边界；报告误差和频谱/图像范围。
- 协议：随机 valid/ready、长停顿、满速、单事务、多帧/多块、复位中断、恢复和配置切换。
- 检查数量/顺序/标志、输出停顿稳定性、无停顿延迟与 II；图像首末行列、小尺寸及边界扩展。
- 校验器以错误注入证明可拒绝数据、顺序、数量和边带错误。不得改变预期迎合实现。

### C. 构建

模块仿真通过后再改集成构建。运行受影响回归，审查锁存器、符号/位宽警告、存储推断、约束和 CDC。相同工具/器件/约束/计数口径做比较。资源和 27 MHz 时序合格后才板测；不靠放松约束掩盖失败。不把工具 Fmax 当作硅片实测频率。

### D. 真实板测

- 接手检查锁、硬件及新鲜采集。使用外部数据注入和独立主机模型逐结果比较。
- UART 不足以连续喂满时，可先外部装载到板内缓冲，再目标速率回放并导出结果。分别报告传输带宽和核心吞吐，不宣称 UART 达到像素时钟速率。
- 现有 UART/FX2 路径先作收发验证；若只有输出采集可用，则明确缺少外部注入验收，不以板内固定自测替代全部功能验收。
- 测试实际连续帧/块、适用反压及性能计数；内部自测作为补充。
- 修复：原版复现→候选通过→重烧复测→原合同回归。
- 新增：独立向量通过→重烧复测→生产集成回归。
- 原始 `.sr`、解码及失败记录保留。采集错误与 RTL 错误区分，不能临时裁剪或放宽校验规则强行通过。
- 参数化 IP 选有依据的代表/边界板测配置，明确其余仅有仿真证据。LA 不证明模拟电气裕量、亚稳态指标或侧信道安全。

### E. 归档与完成判据

状态逐项记录：待盘点/规格完成/RTL完成/仿真通过/构建通过/板测通过/生产集成验收通过/阻塞。隔离候选板测通过不等于生产集成通过。

单核验收要求实际数据接口可用、独立测试合格、资源/时序合格、真实板测及重烧通过、生产版本可追溯、文档和复现命令齐全。

总 goal 要求全清单需求有对应实现和合格证据，且至少一条 DSP 与一条 ISP 代表性组合链完成输入到输出的集成验收。未经用户接受的裁剪、工具阻塞、预算耗尽或阶段结束不能记作总目标完成。

## 10. 执行与汇报

先建立并保存能力/缺口矩阵、需求追踪表、依赖图、分批计划及验收配置，然后直接执行无歧义工作。常规实现选择自行决策并记录；影响算法定义、器件或性能承诺的缺失信息才询问，同时继续独立任务。

复用已完成且仍适用的证据，不无理由重复综合与板测。每批报告改动文件、运行命令、PASS/FAIL、资源影响、证据路径、限制及下一步。持续推进，保持可接续状态，不只给计划后停止。
