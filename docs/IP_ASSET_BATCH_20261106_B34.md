共41项实际PASS子进程、15次成功有限仿真；另有1次保留的色调映射TIMEOUT，未计为PASS。四包均有 `LINT_PASS + UNIT_SIM_PASS + HW_UNVERIFIED` 的限定证据；LINT_PASS只代表Icarus语法/展开。卷积入口另标记新组合的 `INTEGRATION_CANDIDATE`，不继承基础核的历史物理资格。未运行综合、PnR、STA、板测、PPA或大回归。

调度器三组参数核对1862个周期、170条控制命令、36次launch、340个响应保持周期和50个guard等待周期。日历按物理时钟推进，STOP不取消已经授权的链路预留；门边界按采样前的当前窗口判定，launch仅在接收方允许的采样边沿成立。FIFO采用既有规范源，避免将跨门关闭后可能陈旧的held grant当作正常ready/valid输出。该能力不宣称IEEE TSN协议合规。

频带核四组参数核对152条结果、20627次输入握手（含取消设置）、68条命令、456个保持周期及16个复位场景。包含MAX_BINS4096/BANDS8的最大功率与精确宽累加、零功率、重叠/单点频带、阈值相等、峰平局、非法高位/倒序/空频带和I/Q真实平方链。能量及一阶矩保持整数精确值，频率/PSD单位转换由调用方处理。初始Python助手在函数体执行前发生语法错误，零次模型/HDL调用；原字节和诊断已保存，修正两处token空格后才取得本批正式10项证据。

色调映射采用本包独立的max范数、有理数压缩公式，不宣称OpenCV/Reinhard逐位一致。1×1、7×5、128×1、1×128的完整回放通过；原128×128完整回放达到20秒子进程期限并完成进程树清理。即使原始stdout最终含PASS标记且退出码0，资格仍为 **TIMEOUT**，没有升级、修改RTL或重跑完整测试。随后单独一次保存向量的定向检查通过，覆盖16384像素完整采集/统计、曝光、64个输出和显式abort。有效数值比较共3480像素（3416完整小/轴帧输出加64最大前缀）。最大完整输出尚未取得资格，默认32×24实例只有语法检查；全部输出/完成握手均必须受公共CE限定。最大786432位帧RAM另标器件容量HIGH风险。

卷积入口复用原字节3×3行窗口和B33 INT4矩阵/RNE核。三组参数核对98条帧响应、1779个输出、267次配置、2223个输出保持周期、490个完成保持周期及15次复位（12次在途取消）。覆盖非幂次尺寸、中心抽取锚点、跨第九tap、通道/空间顺序、先舍入后零点、缺配置、标记错误、源间隙、反压与恢复。错误标记仍按配置消费并产生临时输出，最终帧响应决定整帧丢弃；不能当作原子错误旁路。尺寸/配置拒绝前的像素隔离有RTL审查支持，当前仿真没有在拒绝期间持续主动驱动s_valid，未将其写成直接对抗测试证据。
