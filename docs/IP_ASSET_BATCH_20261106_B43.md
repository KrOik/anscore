事件合并核为每个 feed 保留一个完整头事件，用未修改的 RAM deadline
scheduler 选择 `(timestamp, feed ID)`，数据保存在同步单端口 RAM。
FEEDS1..8、DATA_W8..512。每路时间非递减，序号严格递增；watermark W
承诺以后接受的时间至少为 W，所以空且未结束的 feed 只有在 W 严格大于
候选时间时才允许释放。EOS 使用独立状态位，完整 unsigned64 时间域没有
哨兵值。已缓冲的事件可在 EOS 后排空。真实组合连接两个
`moldudp64_itch_rx`，保留归一化字段；心跳、包结束或暂时无数据不推断
watermark/EOS。故障隔离不提供跨模块回滚。三配置核心3360命令、3342实际
future 请求、1274 future GET、20160保持拍和18复位；实际组合9包、7事件、
10管理命令、4复位、1取消。

ADC 核收集固定 N 个 unsigned8 样本，选择连续区间 a..b，令 K=b-a+1、
T 为区间总数、P 为到当前码的累计数，输出精确分子 `K*H-T` 和
`K*P-ordinal*T`，再以共享迭代算子给出 signed RNE QF 值和非精确标志。
均匀理想占据率是前提；零计数只是统计候选，不证明物理失码，也没有正弦
密度校准或置信度结论。N1..65535、F0..16，默认直方图3328逻辑位，最大
4096位；实际256样本触发组合另用2048位采集 RAM。复用原直方图、串行
乘法器、整数除法器和触发窗口。行结果在成功 DONE 前均为 provisional，
晚期内部错误可能已输出前缀。执行前修正 TB 的未接受 future 命令保持，
以及 runner 在解析标记前持久化退出证据；没有工具运行后修改预期。
