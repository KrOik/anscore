# Exact state and correctness argument (source reasoning only)

Let a[0..N-1] be the abstract unsigned W-bit dense array. Reset/CLEAR sets every a[i]=0. ASSIGN(l,h,v) replaces exactly a[l:h+1] by v. MIN(l,h) returns (min a[l:h+1], smallest index attaining that value). Every valid interval is nonempty. There is no arithmetic on stored values, so W-bit extremes never overflow; comparisons remain unsigned. Only index/topology arithmetic uses H+1 or H+2 bits, where H=ceil(log2 N),P=2^H≤256. Complete32-bit bounds are checked before the node traversal; lo<=hi<N implies both endpoints are representable.

Tree node k represents [b,b+s), where s is a power of two and b+s<=P. Its valid domain is the intersection with [0,N). A stored row has (minimum,argmin,lazy,valid). An invalid row contributes no candidate; this is distinct from every W-bit value. A valid non-lazy row summarizes its initialized children by the lexicographic unsigned pair (value,index). A valid lazy row means every valid leaf in the node interval has the stored minimum; its stale descendants need not agree and must not be read directly.

When a legal ASSIGN completely covers a node's VALID domain, one row write installs (v,b,lazy1,valid1); b<N for every visited valid node. Endpoints beyond N in the physical tree are excluded by explicit topology. For partial overlap, a lazy parent first writes both children with its uniform value, their left endpoints and valid=(child-left<N). These writes are acknowledged before either child is read. Traversal then modifies only intersecting children. Pull reads both initialized rows, selects the valid smaller pair (left on equal pair) and acknowledges a lazy0 parent write. Thus the parent's summary and descendants again satisfy the invariant. A non-lazy partial parent's children already satisfy it. Disjoint nodes return without mutation. Induction over this finite traversal proves only the requested dense range changes; no other command can observe intermediate private writes.

A query reads only overlapping valid nodes. For full coverage, the stored summary is the answer candidate. For a lazy row under partial coverage, every leaf in the intersection equals the row value and its first legal index is max(query-low,node-left); this is not the old row argmin when the intersection starts later. For a non-lazy partial row, visit both children and combine candidates with the same (value,index) order. This yields the exact interval minimum and the smallest absolute tie index. Unlike a generic software lazy mapper, the hardware explicitly carries node-left/span, so assigning a uniform value never tries to recover the left endpoint from an old argmin.

The stack holds at most H active ancestors; H+1 rows are declared. At DESCEND span>1, halve it and increment depth. A RETURN first visits the saved right child, then restores the parent and decrements depth. Each node is completed once and no runtime recursion occurs. For N=1,H=0, legal intervals are [0,0]; all visits are covered and no DESCEND or child address exists. Physical node addresses are1..2P-1. Parent child arithmetic is performed only for an internal node, so it cannot produce0 or2P.

Reset invalidates all control/RAM responses, then acknowledged root uniform0 establishes the whole-array invariant without touching descendants. Partial ASSIGN must push this fresh root or a fresh uniform descendant before stale data is accessible. A reset during private partial writes therefore has the same fresh-zero postcondition as idle reset. CLEAR overwrites the root under an owner and finishes before valid; stale descendants remain protected by the same invariant. Concurrent or orphan external responses do not exist because this RAM is internal and shares reset.

The above is source reasoning, not formal-tool proof or executed verification. Fixed finite tuples and reset probes are planned independently and remain NOT_RUN.
