# Persistent RAM range assignment and minimum index

RTL_CANDIDATE / HW_UNVERIFIED. Source authoring only. Preparation, oracle evaluation, lint, compile, simulation, synthesis, PnR, STA and board execution are NOT_RUN. AUTHOR_SEAL.json freezes the author source and grants no execution approval.

`ram_range_min_index` retains an unsigned value in each of N dense buckets. ASSIGN replaces all values in a closed interval. MIN returns that interval's minimum and the smallest absolute index on a tie. CLEAR restores every bucket to zero. This adds bulk interval replacement and non-invertible interval argmin to the existing point-SET/range-sum/weighted-SELECT Fenwick index. It is neither an ordered-key enumeration nor a global heap/deadline queue. There is no host-built tree, external memory, data frame, payload transport, autonomous tick or precomputed output image.

## Parameters and ports

BUCKETS is every integer1..256 (default64); VALUE_W is1..32 (default16); TAG_W is1..32 (default8). No derived-width override exists. Unsupported values elaborate the named missing module `ram_range_min_index_invalid_parameters__see_README`. All value bit patterns, including zero, high-bit-only and all ones, are valid exact unsigned integers; no sentinel, rounding, saturation, fixed point or tolerance is used.

All activity shares one rising-edge clk. rst_n is asynchronous active-low control reset, shared with the internal RAM. There is no public CE or CDC. Commands transfer on c_valid&&c_ready; responses transfer on r_valid&&r_ready. Hold every source field while blocked. One command owns the service through response retirement; c_ready stays low during ownership and there is no retirement-edge fallthrough. r_valid and every payload bit stay stable under arbitrary sink stalls.

| Signal | Width | Meaning |
|---|---:|---|
| c_op |2|0 ASSIGN,1 MIN,2 CLEAR,3 BAD_OP|
| c_lo,c_hi |32 each|Complete unsigned inclusive bucket bounds, validated before narrowing|
| c_value |VALUE_W|ASSIGN replacement; ignored for MIN/CLEAR/BAD_OP|
| c_tag |TAG_W|Opaque echoed tag|
| r_op,r_status |2 each|Captured operation;0 OK,1 BAD_RANGE,2 BAD_OP;3 never generated|
| r_index |32|ASSIGN low bound or successful MIN argmin; zero for CLEAR/error|
| r_value |VALUE_W|ASSIGN installed value or successful MIN value; zero for CLEAR/error|
| r_tag |TAG_W|Captured tag on every response|

ASSIGN/MIN require lo<=hi<BUCKETS; an invalid command changes no logical value. Checking the complete c_hi and order also rejects c_lo>=N without allowing high32 aliasing. CLEAR ignores lo/hi/value, even all-one values; opcode3 always yields BAD_OP independently of those fields. Equal bounds are legal. All buckets exist and initially hold0, so MIN has no empty/not-found result. Values and index tie-breaking use ordinary unsigned order.

ASSIGN and CLEAR finish all private writes before their first OK valid. Response ACK releases an already completed operation; it is not a commit or rollback boundary. Invalid output fields while valid=0 are not snapshots. Unlimited output backpressure gives no unconditional whole-workload deadline.

## RAM scheduling and reset

The production dependency is the unchanged canonical `../../system/common_scaffold/memory/src/cip_sync_sp_ram.v` (SHA256 04c0fe8416308c7e9a295d582dc7fee5fd8bbadf2fe4e745632543588c4f7619). Its shared CE is tied1, every write uses full byte strobes, write-response old data is ignored, and every request is followed by its single response ACK before another request. Both files.f and example/files.f use the PACKAGE ROOT as base. The example range_min64 exposes every port at default parameters. No new list-base exception or package-local duplicate RAM is introduced.

A finite stack walks one complete binary tree in synchronous RAM. A uniform lazy row represents its whole valid subtree; partial ASSIGN pushes the old uniform value to both children before descending. A return path reads both children, combines valid (minimum,index) pairs, and writes the parent with lazy=0. MIN can answer a uniform row using the intersection's left endpoint without touching stale descendants. Padded leaves have explicit valid=0; all-ones values remain ordinary data. MATH.md proves the invariant and COST.md gives finite state/clock bounds.

Reset assertion immediately masks public ready/valid and cancels the owner, held response and pending RAM response. RAM data and stack arrays are not reset. After release, BOOT writes only root to valid/uniform0, consumes that write response, then opens c_ready. Every prior bucket is logically0; no stale child can be read without first being reconstructed from an ancestor. N=1 has no child accesses. CLEAR uses the same root overwrite under normal command ownership. Reset discards even earlier completed values, rather than restoring a previous transaction snapshot. Callers discard canceled responses. Deassertion must satisfy recovery/removal; this module is not a reset synchronizer.

Boot ready is presented after4 release clocks and sampled by the TB within5; CLEAR valid is presented3 periods after acceptance and sampled within4. Both retain the frozen8-clock bound. Every legal command has a conservative sampled first-valid bound256*(ceil(log2 N)+1), at most2304 clocks. These are source-derived bounds for the fixed internal RAM, not measured performance; no external RAM stall is assumed. There is no arbitrary runtime recursion or array reset sweep.
