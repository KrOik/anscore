# Storage, ports and finite cycle proof

Only one unchanged cip_sync_sp_ram is instantiated, with ROW_W byte-padded data, ADDR_WIDTH=H+1 and DEPTH=2P. Logical node bits are 2P*ROW_W, ROW_W=8*ceil((W+max(1,H)+2)/8). Default N64/W16:128*24=3072 bits. Maximum N256/W32:512*48=24576 bits. N5/W9:16*16=256 bits. Row0 is allocated but unused. All-ones data is legal because a separate valid bit handles padding.

Stack declarations contain (H+1)*(3*(H+1)+1) bits: parent node/left/span and right-visited flag. Default154, maximum252. Meaningful scalar declarations including the RAM's response data/valid/error total116+5W+T+4(H+1)+SPW+3ROW_W+2IW, where IW=max(1,H),SPW=max(1,ceil(log2(H+1))). Default319, maximum508. Stack+scalars total473 /760 logical bits. This excludes the RAM array, combinational wires/function arguments and the primitive's static byte-loop iterator; it is not a synthesized FF count. Padding/unused state may optimize away. No multiply, divide or DSP operator exists.

A transaction is launched by a normal control-state edge, accepted in MEM_REQ at the next edge, and acknowledged in MEM_RSP one edge later. A read copies rsp_data only at ACK; a write ignores read-first payload. bus fields do not change while waiting. The next request cannot launch until the return control state, so the single response slot is empty at each request. Internal fixed RAM has no unbounded backend stall. Read/write addresses do not rely on a collision bypass or dual ports.

For H>=1 a contiguous interval has at most2 partial nodes per level, hence partial nodes A<=2H-1, terminal covered nodes C<=2H, and total visits V=2A+1<=4H-1 (use the looser4H+1 uniformly). A partial ASSIGN uses at most six RAM transactions: parent read, two lazy-child writes, two pull reads, one parent write. A terminal covered ASSIGN uses one write. Therefore M<=6A+C<=14H-6; the uniform looser M<=14H+1 also includes H=0's one root write. Among non-bus states, VISIT/RETURN contribute at most2V, NODE/PUSH_RIGHT/DESCEND at most3A, and PULL_LEFT/PULL_SAVE/PULL_MERGE at most3A. Thus at most20H+O(1) normal state edges plus2M bus edges occur. Including acceptance/response sampling,64H+16 is a conservative integer bound. H0's direct assign is presented4 clocks after acceptance and sampled within5, safely below16.

MIN has no writes, reads at most4H+1 nodes and uses at most the corresponding VISIT/NODE/RETURN plus2H DESCEND and2 bus edges per read. Including sampling,24H+12 is conservative. Its root-only query is presented5 periods after acceptance and sampled within6. Error valid is presented on the accepting edge and sampled on the next. All these bounds are strictly at most256*(H+1), for every H0..8. TB first-valid includes the sampled edge and retains the same frozen256*(H+1), maximum2304; no bound was relaxed after execution because no execution occurred.

After release BOOT launch, MEM_REQ, MEM_RSP and BOOT_DONE are four rising edges; c_ready becomes high after edge4 and is sampled by edge5. CLEAR launches in its acceptance edge, then MEM_REQ/MEM_RSP/CLEAR_DONE consume three periods; valid is sampled by period4. Frozen boot/CLEAR bound8 covers both. Arbitrary public response stalls add unbounded owner occupancy and are excluded from first-valid, not hidden in these internal cycle counts. The two finite TB modes constrain sink stalls for their own watchdog only.

The maximum280-command main program has a conservative first-valid budget280*2304=645120 cycles before its small fixed stalls; the TB total watchdog also budgets all11 reset jobs' fixed prefixes/eight-row fresh programs. Each simulator/compiler process tree still has a hard20-second wall-clock ceiling with no retry or downsizing. Runtime is NOT_RUN; finite cycle bounds do not claim a measured wall-time or clock frequency.

Likely timing paths are row compare/index tie-break, topology bounds and stack address selection. The source contains separate query-best and pull-row comparisons; mapped comparator sharing is unknown. There is no II1 goal. BRAM/LUT/FF mapping, frequency, device fit, physical routing, power and board behavior are unmeasured. Root has not authorized synthesis/PnR/STA/board work.
