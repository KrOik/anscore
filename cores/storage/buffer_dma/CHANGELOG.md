# Changelog

## 0.1 — 2026-10-21

- Added synchronous descriptor ring with exact capacity including prefetch,
  high-water/stall counters and full pop/push replacement.
- Added four-slot ownership controller, fixed per-producer ping-pong or shared
  allocation, per-consumer commit queues, abort/error handling and reset recovery.
  Both modes pass two-writer/two-reader actual BRAM tests with Python golden.
  Payload block-mover RTL and physical acceptance remain pending.

- Added synchronous byte-masked mem_port_bram and guarded byte addressing.
- Added four-client round-robin arbiter, independent response reservations and
  per-channel request/completion/stall counters.
- Added internal BSRAM reference and independent Python word/CRC regression.
- Two writers/two readers pass 64 test-owned blocks, contention/backpressure,
  errors and reset cases. Isolated GW5A synthesis passes. Full DMA remains open.

- Added acknowledged single-descriptor read/write word DMA and executable BRAM regression; subsystem integration remains pending.

- Integrated two writer / two reader DMA engines with actual RTL slot ownership, arbitration and 1024-word default BSRAM. Added full stream regression and Python golden verification in both allocation modes.

- Added passive four-stream byte/frame/stall, cumulative/per-frame CRC32 and inclusive transfer-duration monitors; extended independent Python golden checks.

- Added per-consumer allocation-to-read-completion latency last/min/max/sum, elapsed time, exact allocation wait count and slot occupancy peak; independent scoreboard and manager regression PASS.

- Added transport-neutral coherent CSR bank, reusing canonical sys_register_snapshot; integrated 51 metrics, documented addresses, response and malformed-access tests.

- Added strict host snapshot decoder and wrap-aware interval byte-rate reporting; full 51-word simulated CSR dumps, ID bracketing and decoded JSON evidence now generated by integration regression.

- Added synthesizable seeded two-source/two-sink selftest, sticky completion/error, per-source sequence checks, timeout and eight debug probes. Independent golden verifies restart, replay and injected corruption; watchdog tested separately.

- Added serialized CSR control routing, start/seed/mode/result registers,11-pin25K UART/probe top, complete bit-serial simulation and reproducible route/pack build script.
