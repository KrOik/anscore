# 来源与交付边界

本批16个`rtl/sys_*.v`是本工程新增原生RTL实现；没有从第三方RTL仓库复制源代码。`ip/*/manifest.json`记录模块、参数边界、源文件SHA256、测试入口和板级模式。板级适配器、UART工具、不同参数和profile不计为额外IP。

前批56核的来源与合同保留在`cores/system/utility_library`，本批只引用它们复验。发布包中的这些依赖按原文件保存，不修改其权限或许可证。OSS工具、cocotb、paramiko和pyserial是验证环境依赖，不编入新增核。

“知识产权可用”在本次工程交付中落实为可追溯源代码、独立模块边界、规格、模型、测试、资源和原始实测证据。专利新颖性检索、权属/许可证法律审核、商标或产品认证不属于已有测试结果；没有把通用电路功能或测试PASS声明为授权专利。
