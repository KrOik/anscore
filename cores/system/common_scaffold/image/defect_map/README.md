# Static calibrated defect-map RAW repair

`defect_map.sv` implements full-frame repair from a host-supplied **one-bit-per-pixel static calibration mask**. The host supplies bad/good flags only. RTL searches the actual captured source frame and computes replacements itself. Default is WIDTH=16, HEIGHT=12, BITS=12; WIDTH/HEIGHT are1..256, BITS is8/10/12. N and AW are derived parameters and must remain consistent with geometry. All storage reads are synchronous and RAM contents are not reset.

For each marked pixel `(y,x)`, RTL examines every original source coordinate `(a,b)` whose map flag is good and whose row and column parity both match the target. It minimizes `(a-y)^2+(b-x)^2`, sums **all** good donors at the minimum distance, and outputs `(sum+floor(count/2))/count`. This is exact nearest rounding with half ties upward. Valid original pixels pass through unchanged. No repaired output is ever written back into the source RAM or used as another donor, so arbitrary clusters cannot propagate fabricated values. Search has no finite radius limit. If a phase has no good donor anywhere in the frame, output is the START-latched cfg_fill, with m_invalid=m_unrepaired=1 and m_repaired=0.

The existing CFA ABI is accepted: cfg_pattern0=RGGB,1=GRBG,2=GBRG,3=BGGR, snapshotted on START. Equality of the two coordinate parity bits identifies the same CFA phase for **every** pattern, so correction results intentionally do not depend on pattern. The two green phases stay distinct; this does not mix green sites from different sensor phases. Border/thin-image handling uses real in-bounds coordinates only, with no mirror padding or invented donors.

Two synchronous mask banks permit loading the inactive map during an active frame. cfg_begin starts a new map transaction. Write every cfg_index0..N-1 with cfg_bad0/1 in any order, then assert cfg_commit_valid until cfg_commit_ready. A distinct-address completeness bitmap prevents duplicate writes from faking a full map. Commit occurs only between frames after DONE acknowledgement; a pending commit suppresses map writes and waits for this boundary. The frame uses its START-latched map bank throughout. An incomplete/bad-index/aborted transaction preserves the published map. cfg_done_valid remains asserted until cfg_done_ready is accepted. A zero map and an all-bad map are both valid complete maps.

Interface follows enabled ready/valid transactions: every accepted transfer requires CE on the rising edge. Source ports are s_pixel/s_valid/s_ready/s_sof/s_eol/s_last. Sink ports are m_pixel/m_valid/m_ready/m_sof/m_eol/m_last, m_repaired/m_unrepaired/m_invalid, and m_status (0 original,1 repaired,2 invalid fill). All sink data, markers and status hold through backpressure/CE pauses. START uses start_valid/start_ready; supply cfg_pattern and cfg_fill at that handshake. Terminal done_valid/frame_error/error_code hold until done_ready. Restart after acknowledgement without reset.

Configuration error codes:1 incomplete map,2 out-of-range map index,3 cfg_abort,4 illegal configuration state. Frame error codes:1 malformed SOF/EOL/LAST,2 START without published map,3 active abort,4 illegal frame state. Synchronous active-low reset overrides CE and invalidates map/control while leaving RAM untouched. Hold abort through an enabled edge; it immediately suppresses visible output and terminates on that edge. A partially emitted aborted frame must be discarded. A source that stops mid-capture must abort/reset; there is no source watchdog.

This is deliberately serialized. Each good output takes three enabled processing cycles; each bad output takes2*N+4 enabled cycles, including a scan of every source address. Including capture, the all-bad upper bound is2*N*N+5*N enabled cycles, excluding START/DONE/configuration and external stalls. This is complete functional search, with no real-time camera throughput claim. Maximum distance130050 fits32bits. The accumulator BITS+AW+1 and count AW+1 cover every original source sample and the half-count rounding bias; variable unsigned division is synthesized in fabric.

Main oracle enumerates every original good same-phase donor independently. Actual SciPy cKDTree execution independently checks nearest distance and the exact nearest-radius tie set at every repairable target. A raw KD-tree k=1 selection can choose an arbitrary tied sample; this design instead averages the full tie set, an explicit difference rather than a tolerance. Main regression covers144 frames/6576 pixels: all four patterns at8/10/12bits,1×1,1×7,7×1,2×2,9×7,16×12, complete zero/all-bad maps, large clusters, random maps, corners, whole-phase failures, and maximum values. Numeric limits add16 frames/1324 pixels with exact .5 and sub-half means, full-scale accumulations,256×1 and1×256 axis boundaries, and7 rejected illegal parameter configurations. Protocol adds21 healthy frames/504pixels plus4 failed map transactions, all3 source marker errors, all7 active-phase aborts/resets with CE pauses and recovery, and actual simultaneous inactive-map loading during a stalled frame with pending commit held through DONE.

Standalone Gowin synthesis with -noalu -nodsp: default16×12/12bit1771 LUT-class,370FF,2DPB+1DPX9B,0DSP;24×16/12bit2280 LUT-class,568FF,2DPB+1DPX9B,0DSP. LUT-class counting includes ALU/MUX and4*RAM16SDP4. These are isolated synthesis results; no place/route, timing or board/camera quality acceptance is claimed.

Actual mature source downloaded for method review: dcraw bad_pixels static `.badpixels` calibration list and fcol same-color neighborhood averaging. URL/SHA256/algorithm excerpt are in references.json; optional fetch_references.py refreshes metadata and deletes the downloaded file. No third-party source is copied. dcraw's finite-radius, same-color and in-place sequential arithmetic differ from this module's full-frame, exact-phase, original-good-only, all-minimum-distance-tie arithmetic. No claim of dcraw bit equivalence or complex directional reconstruction is made. Routine tests generate all their own vectors and require NumPy/SciPy but no network or camera.
