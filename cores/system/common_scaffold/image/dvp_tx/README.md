# Fixed-timing DVP transmitter

`dvp_tx.sv` accepts real pixel streams and generates unbackpressured parallel camera byte samples. It is independently implemented after a repository-wide search found no equivalent DVP transmitter. Host stalls and host CE never stretch an active sensor byte period. This module has no sensor-output ready input.

ABI: `clk/rst_n/ce/start_valid/start_ready/abort`; captured `cfg_width/cfg_height[15:0]`, `cfg_mode` (one bit:0 gray8 low8,1 RGB888 quantized to RGB565), `cfg_big_endian`, `cfg_vsync_active_high/cfg_href_active_high`, `cfg_hblank/cfg_vblank_lines/cfg_byte_period[15:0]`. Input `s_pixel[23:0]/s_valid/s_ready/s_sof/s_eol/s_last` uses CE-qualified handshakes. Captured `image_width/image_height[15:0]/image_mode` describe the active operation. Output `data[7:0]/vsync/href/sample_valid` has no backpressure. Completion uses `done_valid/done_ready/frame_error/error_code[7:0]`.

RGB888 quantization takes R[7:3],G[7:2],B[7:3] to form RGB565, then emits high/low bytes according to captured endianness. Gray8 emits low8 only. SOF/EOL/LAST must exactly match configured pixel coordinates, and are checked on every accepted pixel. No pixel is duplicated or invented to conceal input starvation.

Before timing starts, PREFILL waits for `min(width*height,FIFO_DEPTH)` complete accepted pixels. This is a specified full-buffer pixel threshold, or the complete image if smaller. The synchronous RAM FIFO has FIFO_DEPTH slots plus one pixel holding register. A full RAM ring always deasserts source ready, even on a prefetch/read cycle; source refill waits until the following clock. This prevents cross-port same-address BRAM read/write ambiguity, while physical output timing continues unchanged. Prefetch can occur with CE0. Sample output remains disabled in PREFILL; missing host input cannot produce a partial frame. Abort or bad markers during PREFILL report immediately with zero sensor ticks.

Each generated line contains `width*(mode?2:1)+hblank` byte ticks. HBLANK is leading blank: each active line starts with hblank inactive-HREF samples, followed by all active bytes. This intentionally provides inactive HREF at the first falling VSYNC sample, allowing the frozen DVP receiver to acquire a complete frame. The frame consists of vblank_lines complete initial blank lines, height active lines, and vblank_lines complete trailing blank lines. VSYNC is active for vertical blank; HREF is active only during image bytes. Blanking data is zero. The final active-line HREF falling and VSYNC rising coincide, which is supported by DVP RX.

Each sample_valid pulse is exactly cfg_byte_period clocks after the previous pulse, beginning after PREFILL. Period1 means sample_valid remains asserted for consecutive samples. Data/sync pins update only on ticks, except configuration/reset initialization; between ticks they hold. RUN timing continues at CE0. CE gates host START, accepted pixels, abort and DONE acknowledgment only. Successful DONE occurs after the final trailing blank sample has been generated; the sample is observed by a synchronous receiver on the following clock. After DONE, sample_valid deasserts and data0/VSYNCactive/HREFinactive remain held. DONE/error are held until CE-qualified done_ready; next START clears counters and captures a new configuration.

Underflow on an active pixel, bad accepted markers, or host abort during RUN immediately latch an error, discard FIFO pixels and stop input acceptance. From that error's tick onward the generated samples are deterministic data0/VSYNCactive/HREFinactive while the original line/byte counters and tick cadence continue through the original complete frame schedule. A marker error between ticks changes pins on the next tick. There is no elastic stall or early DONE: DONE waits for the original safe trailing-blank boundary. An already latched error cannot be replaced by a later abort. All emitted data is provisional until successful DONE; consumers must discard an erroneous frame, including any prefix already emitted. A downstream receiver may report an error when forced blanking truncates its active line; that is intentional invalid-frame cancellation, not successful video.

Reset is active-low synchronous, independent of CE, and immediately cancels timing and returns inactive blank pins. Reset is explicitly the exception to safe-timed abort. Idle/DONE ignore abort. If simultaneous marker failure and host abort occur before any earlier error, host abort takes priority. Missing host input in PREFILL has no invented timeout; host may abort.

MAX_WIDTH/MAX_HEIGHT legal1..4096, defaults640/480. FIFO_DEPTH legal2..4096 including nonpowers of2, default1024. Configured dimensions must be nonzero and within static limits. HBLANK, VBLANK_LINES and BYTE_PERIOD each legal1..4096. Horizontal/vertical counters include blanking without overflow. Error codes:01 invalid static/runtime configuration;02 FIFO underflow;04 input SOF/EOL/LAST error;08 internal state;09 host abort.
