# v103 NLM/morph production preflight

This directory is an isolated, no-apply production preflight for the frozen
v103 opening, closing, and NLM candidate. It does not edit production RTL,
filter manifests, or the frozen OP0/OP1/OP2 handoffs.

`run_preflight.py` stages the current production `img_filter_frame_engine.v`
and `img_filter_exp_weight.v`, then runs the frozen independent 8-bit and
12-bit vectors, the board self-test wrapper in Icarus for all three operations,
POR coverage, a production-width/CE/reset contract test, and the existing
`image_core` regression in a disposable copy. It does not invoke synthesis,
place-and-route, or board programming. Simulator executables, copied workspaces,
and temporary vectors are removed after each run. Source snapshots, full text
logs, fixture vectors, and JSON summaries remain in a timestamped `evidence/`
directory here.

The candidate's frozen width/reset bench named multiplier/divider pipeline
states that do not exist in the current production engine. The production board
simulation therefore changes only the staged OP2 reset trigger from candidate
`DIV_MID` to production `NWEIGHT`; the frozen bench is never edited. The local
contract bench checks PIXEL_W=1 acceptance, PIXEL_W=16 rejection, CE hold while
the production NLM arithmetic phase is active, asynchronous reset, and replay.

Run the simulation preflight from the repository root:

```powershell
python -B cores/system/common_scaffold/image/filters/sim/production_nlm_morph_v103_20261017/run_preflight.py
```

The expected current result is a passed local simulation suite with
`WAITING_FOR_ROUTE_AND_BOARD_EVIDENCE`. Exit code 2 means that local checks
completed but the production integration gates are still missing. For an audit
without local simulation, use `--gate-only`; to omit the separately staged
image-core run, use `--skip-image-core-group`.

The integration gate reads the production route and board evidence formats
directly. Each OP must have `opN/build_opN_router1_seed3_summary.json` with
`status: "BUILD_PASS_NOT_BOARD"`, passing `gates` for route completion,
15K-LUT/4-DSP limits, 50 MHz setup, hold, and official packer import; `util`
with `lut4` and `mult12`; `fmax_mhz`; and `input_top25k_sha256` matching that
OP's `top25k.json`. The board gate reads `board_validation_summary.json` from
`validate_op_three_sram_loads.py`: exactly three distinct `loads`, each with a
relative `record` and matching `record_sha256`. It verifies each UART record's
`status`, SRAM-only programming result, JTAG IDCODE `0x1281b`, byte-exact UART
PASS, and exact CRLF-terminated frozen `expected_uart.txt`. The top-level board
summary status is optional; the individual UART records are authoritative.

The route and physical-board files are evidence contracts, not generated by
this preflight. A simulation PASS does not satisfy either gate.

## Final three-OP release gate

`run_final_integration.py` is a read-only, fail-closed readiness gate. It
requires each OP0/OP1/OP2 to independently pass its frozen-input audit,
qualified-synthesis handoff and full Yosys log, mapped-netlist resource and
structure checks, official route summary at 50 MHz with zero hold violations,
and three distinct SRAM-only board records with exact CRLF UART bytes bound to
the routed bitstream. It also requires an independent production-source
regression before it reports `READY_FOR_SEPARATE_APPLY_REVIEW`.

The runner does not implement an apply operation. Each ordinary audit keeps a
small, hash-verified copy of the current production RTL under its timestamped
evidence directory, then reports whether the production sources differ from
the frozen candidate. `--run-production-regression` invokes the existing
independent Icarus production suite; it does not run synthesis, PNR, or board
programming. Host fixtures use disposable temporary directories:

```powershell
python -B cores/system/common_scaffold/image/filters/sim/production_nlm_morph_v103_20261017/run_final_integration.py --self-test
python -B cores/system/common_scaffold/image/filters/sim/production_nlm_morph_v103_20261017/run_final_integration.py --run-production-regression
```

The current read-only gate-only audit verified all three freezes, but no OP has
qualified-synthesis, routed, or physical-board evidence yet, so release is
blocked. The current production engine and exponential-weight table also have
different SHA256 values from the frozen v103 candidate; a future v103 release
would change those two production files. No apply was performed. See
`UPSTREAM_REFERENCE_AUDIT.md` for the pinned OpenCV reference and license
review; no third-party source was copied into this repository.

## Qualified synthesis wrapper

The frozen `build_op_synthesis.py` has a manifest-recorded SHA256 in all three
OP handoffs, so it is left untouched. `run_qualified_synthesis.py` is a
separate wrapper for a future explicitly assigned synthesis slot. It verifies
the frozen inputs, copies them into a `TemporaryDirectory` inside the selected
OP, runs the official Gowin `synth_gowin -noalu -noabc9 -family gw5a` route,
streams the complete combined log to console and its own evidence directory,
and applies `check -assert`, JSON connectivity and known-primitive checks,
RAM16/generic-cell rejection, exact warning review, and LUT/DSP budgets. It
never runs PNR or board programming.

Host-only gate tests (no Gowin tools and no synthesis):

```powershell
python -B cores/system/common_scaffold/image/filters/sim/production_nlm_morph_v103_20261017/run_qualified_synthesis.py --self-test
```

The warning gate reviews only two exact lines: the full ABC notice
`ABC: Warning: The network is combinational (run "fraig" or "fraig_sweep").`
and `Warning: Replacing memory \\result_frame with list of registers. See image_filter_frame_board_selftest_25k.v:133`.
The latter is the frozen board test's 12x8-bit output scoreboard, not either
production engine frame buffer; Yosys maps those 96 checker bits to registers,
and they remain included in the resource report. Any changed object, source,
line, wording, or other memory warning still fails the gate. The host self-test
checks repeated exact warnings and rejects wrong names, sources, lines, a
one-character change, and a warning for the production `raw` memory.

`requalify_retained_netlist.py` can independently re-audit the existing failed
OP0 synthesis evidence without rerunning Yosys. Its default `--check-only`
verifies frozen input hashes, full-log SHA, successful `check -assert`, the
exact warning allowlist, retained-netlist SHA, official primitive structure,
and resources. It writes nothing. After a PASS, the root integration owner may
use `--execute` to create a separate requalification summary and publish the
retained JSON through the same no-clobber route-handoff routine; the old failed
summary remains untouched.

```powershell
python -B cores/system/common_scaffold/image/filters/sim/production_nlm_morph_v103_20261017/requalify_retained_netlist.py --self-test
python -B cores/system/common_scaffold/image/filters/sim/production_nlm_morph_v103_20261017/requalify_retained_netlist.py --check-only
```

Default invocation prints a frozen-input plan and exits without synthesizing.
`--execute --op N` is the only route that starts Yosys and must be used only
after the synthesis slot is explicitly assigned. The host-only tests include
the real read-only v89j mapped netlist at `image_geometry_frame_selftest_25k`,
known primitive blackboxes, `$scopeinfo` metadata, unknown primitive and `$add`
rejection, warning-prefix detection, and DSP resource categories. Primitive
names are extracted from the local Gowin libraries only after their SHA256
values match the reviewed versions.

`--retain-netlist` keeps a failed-gate mapped netlist in this wrapper's evidence
folder for inspection. When all gates pass, it publishes `top25k.json`,
`top25k.json.sha256`, and `qualified_synthesis_handoff.json` in the matching OP
directory, where the official route reads the JSON. Without the flag, mapped
JSON is discarded with the temporary workspace. No PNR command exists in this
wrapper.

The route/board evidence readers also have a disposable host-only schema test:

```powershell
python -B cores/system/common_scaffold/image/filters/sim/production_nlm_morph_v103_20261017/run_preflight.py --self-test-gates
```
