# Next common/video gap audit

Read-only repository audit, 2026-10-19. No new RTL, synthesis, board claim or frozen-input changes. Searches covered readable Verilog/SystemVerilog in projects, anscore and references, excluding build/evidence, board snapshots, generated netlists and encrypted/vendor black boxes. anscore duplicates are not additional cores.

| Candidate | Actual reusable source and capability | Gap decision |
|---|---|---|
| AXI4 full multi-master/multi-target crossbar | `stream_bus/axil_multi_crossbar/axil_multi_crossbar.sv` is AXI-Lite only; `stream_bus/rtl/sb_axi4_native_bridge.v` and `sb_axi4_burst_bridge_placeholder.v` implement a single full-AXI endpoint/native bridge with AWLEN/ARLEN, IDs and LAST, not NxM arbitration/routing. `production_system_ip_25k/rtl/sys_axi_lite_interconnect.v` is Lite. No readable full-AXI crossbar module found. | **Missing**, high priority. Reuse endpoint as target/test fixture; need burst ownership, W routing, ID response return, target arbitration, decode error draining and explicit outstanding policy. |
| AXI4-Stream asynchronous FIFO | `cores/signal_processing/dsp_isp_library/infra/asyncfifo/rtl/async_stream_fifo.sv:27`: real two-clock ready/valid FIFO, Gray pointers, synchronizers, synchronous held output, parameter WIDTH/DEPTH; payload only, sidebands can be packed losslessly. `cores/system/stream_bus_library/rtl/sys_packet_async_fifo.v:3`: real two-clock packet store-forward FIFO, explicit last and atomic oversize drop, one complete packet in flight. | **Base function exists**. Do not develop a duplicate FIFO. Optional narrow AXIS adapter packing TDATA/TKEEP/TLAST/TUSER, with explicit reset/discard contract and CDC timing constraints; separately test reset recovery rather than inheriting comments as proof. |
| Video frame-rate converter | `signal_video/rtl/cip_image_framebuffer.v`: command-driven write/replay, write-only/read-only external-memory frame adapter; one outstanding memory request, one clock. `memory/video_dma_2d/video_dma_2d_axi32.v`: frame transfer building block. Existing frame-difference/multiframe blocks calculate images, not temporal scheduling. No readable frame-rate-converter scheduler found. | **Missing**, high common/video priority. Need complete-frame ownership, independent producer/consumer frame cadence, repeat/drop policy, no tearing, underflow and timestamp/counter behavior. Existing store/DMA can be reused; interpolation need not be implied. |
| I2S/TDM multichannel serial RX/TX | `cores/system/ip_series/src/ips_i2s_tx_master.v:29` is stereo left/right TX, programmable slot/word alignment, underrun accounting. `ips_i2s_rx_slave.v:33` is stereo sampled-pin RX with slip/loss/drop counters. `projects/micarry_audio_capture_20k/src/micarry_i2s_slots.v:1` receives four parallel stereo data wires (8 channels), fixed clocks and 24-to-16 truncation, RX only. `cores/acceleration/operator_library/rtl/acc_tdm8_demux.v:3` accepts already parallel words with channel index; not a physical serializer. `references/Sped0n_eko/.../design/i2s/i2s_recv*.v` are receive-side reference designs. | **Stereo I2S and parallel-lane RX exist; single-wire multi-slot TDM TX/RX missing**. Scope new work to real frame-sync/bit-clock serial slots, configurable channels/slot/word sizes, explicit underflow/overflow and channel boundaries; avoid duplicating stereo cores. |
| SPI slave | `cores/system/ip_series/src/ips_spi_slave_reg.v:32`: synthesizable real sampled-pin slave with tri-state MISO, modes0..3, frame8/16, command read/write register index, sequential pointer, CS restart and short/no-CS counters; actual testbench `sim/tb_ips_spi_slave_reg.v`. Also mirrored in anscore; `comm_20k/src/spi_slave_model.v` is only a model, not counted. | **Not missing**. Reuse existing register slave when its fixed wire protocol fits. A generic streaming slave would be an explicitly narrower new requirement, not absence of SPI slave capability. No new implementation justified now. |

Paths beginning stream_bus, signal_video or memory are relative to cores/system/common_scaffold. Other paths are repository-relative.

Recommended order: video frame-rate converter (reuse frame store/DMA), full-AXI4 NxM crossbar, multichannel serial TDM; AXIS CDC adapter only if integration requires explicit sideband ports. SPI slave should enter reuse/integration work instead of new-core count.
