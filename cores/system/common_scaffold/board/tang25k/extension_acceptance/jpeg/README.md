# JPEG FPGA acceptance fixture

This isolated top instantiates the frozen grayscale JPEG integration and all nine algorithm dependencies unchanged, plus the existing hybrid UART transmitter. It loads q=1, restart interval=1, emits two 13x9 raster frames consecutively without encoder reset, and transmits the actual complete JFIF byte streams directly at 115200 baud. CE is always enabled; UART ready controls output backpressure. Pin mapping and 50MHz clock use the existing Tang25K device flow. No prefix, suffix, line ending, or synthesized expected bytes are transmitted.

Power-up waits 50,000,000 clocks (1 second), then outputs frame0 (411 bytes) followed by frame1 (588 bytes), once. dbg_uart becomes high only after both encoder completions and the last UART stop bit. A capture must open the serial port before SRAM programming and retain all raw bytes. Success requires exactly 999 bytes equal to expected_uart.bin, then independent Pillow decoding and pixel comparison for both frames. A timeout or partial stream is a failure.

ROM inputs are identical to root independent fixture: frame0=(13*x+7*y+23)%256, frame1=Python Random(13*123+9).randrange(256) for 117 samples. pixels.hex records both 117-byte frames. frame0/1.hex and .jpg are retained small reference evidence. They were generated by independent root simulation; the board wrapper's physical UART waveform was independently bit-sampled in simulation and compared byte for byte. Pillow maximum pixel error is 1 for each frame.

prepare.py runs both reference and real UART simulations using auto-cleaned system temp files. build.py first checks all source and vector hashes, uses the shared device_flow in an auto-cleaned C temporary directory, and retains only the packed image, logs, constraint, synthesis script and summary. No JTAG or serial operation occurs in these scripts. simulation_gate.json is simulation evidence; build summary is build evidence. Physical board acceptance must be recorded separately by root.

GW5A routing initially rejected distributed RAM16SDP4 cells; failed logs are retained in attempt_lutram_failed. The isolated build adapter adds -nolutram -nodsp to the temporary synthesis script, keeping true synchronous BRAM and mapping remaining small tables into registers. Frozen RTL and the shared device_flow implementation are unchanged. build_input_sha256.json binds all common source inputs before/after the actual build.
