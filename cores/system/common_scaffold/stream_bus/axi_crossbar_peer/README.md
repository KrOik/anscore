# Independent AXI4 crossbar peer

This directory owns independent verification code only. It does not modify `axi_multi_crossbar`, its validation functions or shared registry. `address_oracle.py` models transfer byte addresses directly: FIXED repeats the initial address, INCR advances from the aligned transfer address after the first beat, and WRAP applies a power-of-two wrap boundary. Each beat exposes actual byte addresses and bus lanes. Decode and 4KiB checks operate on the transferred byte set, so an unaligned one-beat transaction at byte 0xfff is legal while its next INCR beat crosses the page.

The crossbar policy rejects LOCK/exclusive requests, reserved BURST, oversized SIZE, FIXED over 16 beats, illegal WRAP length/alignment, overflow, unmapped or crossing windows. This is a documented implementation subset, not a claim that AXI itself forbids exclusive accesses. A rejected descriptor retains LEN+1 beats for error draining/zero read responses. Write LAST mismatch upgrades OKAY/EXOKAY to SLVERR, preserving prior SLVERR/DECERR. ID mismatch flags but original captured upstream ID is returned.

`python -B address_oracle.py --self-test` runs 18 hand-calculated boundary cases and 12,000 seeded invariant cases. `python -B test_five_channel.py` builds an independent physical five-channel target and two/four master drivers, generates byte-lane expectations from the oracle, and compiles actual owner RTL. It tests 32/64-bit parallel directions and targets, target contention, early W, stalled B/R stability, complete W/R beat counts and reconstructed LAST, metadata/local address preservation, wrong ID/LAST, CE=0 completion, error bursts, unaligned page/window endpoints, 256 INCR and 16 FIXED bursts. Four masters contend on one target for eight synchronized rounds; AW/AR grant traces verify 0/1/2/3 order for this bounded experiment. This is not an infinite-stream fairness proof.

`fetch_references.py` actually retrieves mature alexforencich address crossbar code, PULP AXI address functions, and the ZipCPU burst-address article into memory and records SHA/excerpts. The oracle was written before viewing owner `good_request`, imports no owner code, and does not copy its validation equations. Typed `port_schema.py` is imported by absolute path only to generate wire declarations, not expected behavior. The oracle contains its actual self-test and imports no untracked helper; `test_oracle.py` is a thin compatibility wrapper. All text IO explicitly uses UTF-8.

All scripts use C: auto-cleaned temporary directories for HDL products. Use Python `-B` to avoid caches. Evidence describes ideal RTL simulation only; no board, routed timing, electrical or full AXI formal compliance claim. Five-channel evidence checks every final owner frozen input before and after execution, binds the owner freeze SHA and lists independent peer inputs.
