# Provenance and semantic selection

Implementation and test logic are original ANSCORE work, Apache-2.0; see local
LICENSE. No third-party source or external build script is imported/executed.

Before implementation, read-only HTTPS review of Google's gemmlowp primary
[quantization explanation](https://github.com/google/gemmlowp/blob/16e8662c34917be0065110bfcd9cc27d30f52fdf/doc/quantization.md)
and [Apache-2.0 license](https://github.com/google/gemmlowp/blob/16e8662c34917be0065110bfcd9cc27d30f52fdf/LICENSE)
at pinned commit16e8662c34917be0065110bfcd9cc27d30f52fdf informed the affine
zero-point/scale contract. This RTL is an independent serialized U8xS4 engine;
it does not claim gemmlowp/TFLite bit-exact output-stage compatibility. Web search
was attempted but the service returned HTTP500; official raw GitHub/API retrieval
provided the actual technical text and license. Only technical data was used.

Local semantic review included cnn_infer_25k/int8_dot_stream (signed8 raw dot,
no stored matrix/quantization), cnn_inference/cnn_engine (fixed parallel CNN),
cnn_systolic/src/pe.v (CE product/sum element), stream_sparse_matvec (streamed
sparse coefficients against cached vector), ip_series/ips_quant_int8_sym
(CE-qualified, half-away symmetric quantization), operator_library dot4
(fixed4-tap decimator), and stream_requantize (RNE shift/clamp only).

belongs to its documented configurations, not this new64-to16 composition.

reports/<stamp>/executed_inputs. Final documentation and B33_DELIVERY.json bridge
the exact final bytes to selected successful receipts. No weights are needed
from the network: all configuration enters through local ports; deterministic
test data is generated by the supplied Python helper.
