# manchester_io

Manchester (IEEE 802.5 polarity: a low-to-high mid-period transition is a 1) transform over 32 bit-times per accepted beat, 64 half-bit-time channel samples. Decode (default): a[31:0] are the first 32 channel samples and b[31:0] the next 32, earliest in bit 0, read through a 65-bit pool whose bit 0 is the sample carried from the previous beat. The receiver pairing is (sample 2k, sample 2k+1) at phase 0 and (the carried sample with sample 0, then sample 2k-1 with sample 2k) at phase 1, so a beat always retires exactly 32 bit-times and always carries its own last sample forward. A bit-time is legal only when its two halves differ; the recovered data bit is the second half. Clock recovery scores both pairings: v0 and v1 are the violation counts of this beat and each feeds the saturating EWMA sum0 := clamp(sum0 + ((v0-sum0)>>>2)) and sum1 likewise, and the phase used by the next beat is 1 when sum1 < sum0, 0 when sum0 < sum1 and held on a tie. A beat whose 32 bit-times contain any violation under the phase actually used faults and grows the saturating 6-bit violating-beat streak; a clean beat clears the streak; a streak reaching c[5:0] (0 disables the check) additionally sets the loss-of-lock flag. Encode (c[30]=1): a[31:0] are 32 data bits and the beat emits the 64 channel samples they map to, result[31:0] the first half and aux[31:0] the second half; the encoder is stateless so encode beats leave phase, carry, scores and counters exactly as found unless c[31]=1. c[31]=1 clears phase, carry, scores, streak and counters before this beat's work; c[29:6] must be zero. result in decode mode = the 32 recovered data bits (bit 0 earliest). aux in decode mode: aux[5:0]=v0, aux[11:6]=v1, aux[12]=phase used, aux[13]=phase for the next beat, aux[14]=loss of lock, aux[15]=restart applied, aux[21:16]=violating beat streak, aux[29:22]=sum1-sum0 as a signed 8-bit view, aux[31:30]=0. State: phase state[0], carried sample state[1], sum0 state[9:2], sum1 state[17:10], streak state[23:18], total violations state[31:24], total bit-times retired state[47:32].

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 32. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Sixty-four channel samples are scored for mid-period legality under both candidate pairings in the same cone, so 32 bit-times decode and the clock phase corrects on the enabled edge, where a bit-banged receiver samples one edge per timer interrupt and cannot re-align mid-stream at all.

Independent integer model: `step("manchester_io", a, b, c, state)` in tools/fam_sensing.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 128 distinct responses, 34 fault rows.
