# mt_speed

M/T speed measurement without a divider, one beat, stateful. Pulse count n=a[10:0] is signed 11-bit (sign = direction, magnitude up to 1024 pulses per gate) and the captured period p=b[11:0] is unsigned timer ticks between the last two edges; a[31:11], b[31:12], c[3:0] and c[30:12] must be zero (malformed beat: result=aux=0, fault=1, state kept). c[7:4]=S is the output scale exponent, c[11:8]=T the zero-speed timeout in beats (0 disables it), c[31]=1 restart clears history and timeout. The core takes m = index of the top set bit of p, normalises u = p shifted to the 8-bit window [128,255] and reads the generated reciprocal image r = round(2^17/u), so 1024*2^m/p ~= r and speed = round_up(|n|*r >>> (m+10-S)) with the sign of n (the shift left when S exceeds m+10); |n|*r and every intermediate stay inside one MULT12X12 product and a 32-bit signed sum. An out-of-window u (only possible for p=0 or p=1) reads entry 0 instead of indexing the image out of range. fault=1 when the magnitude exceeds the signed 12-bit domain (over-range, clamped to [-2048,2047]), when n is non-zero but p=0 (no period captured, the classic M-method stall), when n is non-zero and p is non-zero but the scaled word rounds to zero (under-range), when the timeout counter exceeds T, or on a malformed beat. The timeout counter increments while n=0 and clears on any pulse. state[11:0]=previous period, state[23:12]=previous count, state[35:24]=timeout (saturates at 4095), state[47:36]=previous speed. result[11:0]=speed, result[12]=over-range, result[13]=under-range, result[14]=timeout, result[15]=no-period, result[16]=restart echo, result[31:17]=0. aux[11:0]=p minus previous p modulo 2^12, aux[23:12]=timeout counter, aux[27:24]=m, aux[31:28]=S.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A divider is the one thing a control fabric cannot afford per beat; a reciprocal image plus one slice turns M/T speed measurement into a single-cycle fixed-point expression with the stall and timeout flags that a polled quadrature read cannot time.

Independent integer model: `step("mt_speed", a, b, c, state)` in tools/fam_motor.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 111 distinct responses, 36 fault rows.
