# interleave_convex

Convex (stride-skew) interleave address network over a 16-slot symbol window, four symbols per accepted beat. The block lives in state[127:0] as sixteen 8-bit slots; lane j of this beat writes or reads slot a_j = (base + j*stride) mod 16 for j = 0..3, with base held in state and advanced by four every scatter or gather beat, and j*stride built from two conditional adds of stride and stride<<1 because the fabric $mul is not usable here. c[1:0] selects the mode: 0 = scatter the four symbols of a[31:0] (byte j = symbol j) into the permuted slots, 1 = gather the four permuted slots into result bytes 0..3 in lane order, 2 = block reset (the stored block is kept, no symbol is moved and only the counters advance), 3 = malformed. c[5:2] = stride (0..15); stride 0 and stride 8 map two lanes onto one slot for every base, which is the illegal convex pattern and returns result=aux=0 with fault while still advancing the counters. c[29:6] must be zero and c[31]=1 clears the block and the counters before this beat. The whole cone is four add-and-mask address generators, one 128-bit masked write network and a six-comparator duplicate detector: no multiplier, no divider and no memory beyond the state register itself. result[7:0] = block slots 0..3 (mode 0), result = the four gathered symbols in lane order (mode 1), result = 0 (mode 2, or an illegal stride). aux[3:0] = base slot this beat, aux[7:4] = stride this beat, aux[8] = restart applied, aux[9] = illegal stride, aux[10] = first beat since the restart, aux[11] = the block has been written at least once, aux[12] = this stride makes consecutive beats overlap the same slots, aux[13] = two lanes of this beat address the same slot, aux[14] = gather mode, aux[15] = scatter mode, aux[23:16] = the previous beat lane-0 and lane-1 addresses, aux[31:24] = the sum of the four symbols touched this beat. State: state[127:0] = the sixteen interleave slots, state[143:128] = beats since the last restart (saturating at 65535, which raises fault), state[159:144] = the four lane addresses of the last beat (nibble j), state[191:160] = the previous beat a, state[223:192] = the previous result, state[227:224] = the next base slot, state[231:228] = the last stride used, state[232] = block-touched latch, state[255:233] = 0. A malformed beat returns result=aux=0, fault=1 and keeps state. Fault = malformed control, an illegal stride, or a saturated beat counter.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 4. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: An interleave/deinterleave pass in software is a modulo multiply and a conditional store per symbol behind a data-dependent address chain; this network resolves four skewed addresses, the 128-bit masked write, the gather and the duplicate/overlap checks in one enabled beat at fixed latency, so a turbo decoder pays no bubble between the two half-block passes that need the permutation.

Independent integer model: `step("interleave_convex", a, b, c, state)` in tools/fam_fec.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 125 distinct responses, 4 fault rows.
