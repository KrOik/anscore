# pwm_deadband

Complementary PWM pair with run-length dead-band insertion and short-pulse elimination, one beat, stateful. Duty D=a[11:0] and period P=a[23:12] are unsigned counts (P>=1 required); dead band N=b[7:0] and the no-output alarm window T=b[15:8] are unsigned beats (T=0 disables the alarm); b[31:16], a[31:24] and c[28:8] must be zero. c[31]=1 restart (phase, direction, run and every counter cleared before this beat), c[30]=1 selects centre-aligned (triangle) instead of edge-aligned (up-count), c[29]=1 gates the outputs on. On a restart or after the gate has been dropped the run counter is cold, so the first permitted beat is always dead-banded. The reference level is req = (phi<D) edge-aligned, or req = |2*phi-(P-1)| < D centre-aligned with the triangle counted up and down between 0 and P-1; both are magnitude compares of shifted counts, never products. run counts consecutive beats at the same level and the pair is hi = gate && req && run>N, lo = gate && !req && run>N, so the two channels are mutually exclusive by construction and every transition leaves N beats with both gates off; a level whose run length never exceeds N is suppressed and counted. fault=1 when D>P (duty beyond the period), when N>P (the dead band can never be cleared), when hi and lo are ever both on, when the beat counter passes T without a single output beat, or on a malformed beat (result=aux=0, state kept). result[11:0]=run clamped to 12 bits, result[12]=lo, [13]=hi, [14]=req, [15]=gate echo, [16]=mode echo, [17]=restart echo, [18]=duty over period, [19]=dead band over period, [20]=no-output alarm, [21]=overlap, [22]=pulse suppressed this beat, [23]=output changed this beat, [27:24]=transition count (saturates at 15), [31:28]=suppressed count (saturates at 15). aux[11:0]=next phase, aux[27:12]=next run length, aux[28]=req, aux[29]=next direction, aux[30]=hi, aux[31]=lo. State: [11:0]=phase, [12]=direction, [28:13]=run, [29]=req, [30]=hi, [31]=lo, [43:32]=beats since restart (saturates), [47:44]=transitions, [51:48]=suppressed, [52]=output ever seen (sticky).

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Shoot-through kills a half-bridge in one cycle, and a CPU cannot buy the dead band with code: software must either stall the ISR or run a timer peripheral whose update is not aligned to the beat. Here hi and lo are mutually exclusive by construction, the both-off window is exactly N beats, sub-N commands are rejected in the same beat they arrive, and the whole state path is counters and magnitude compares at II=1 with no multiplier and no branch.

Independent integer model: `step("pwm_deadband", a, b, c, state)` in tools/fam_motor.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 122 distinct responses, 20 fault rows.
