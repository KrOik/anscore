# fadd_s32

Minimal IEEE-754 binary32 add/subtract, one operation per accepted beat (latency 1, not stateful): result=a+b when c[0]=0 and a-b when c[0]=1, with c[31:1] required zero. The datapath is the classic three-stage unit: exponent compare (both operands are decoded to the unified form v=mant*2^(Eff-150) with Eff=max(E,1) and mant=(E==0)?M:(M|2^23), so subnormal inputs enter the same magnitude comparator as normals and the larger operand is always routed to the A side), a 26-position alignment shifter that then adds or subtracts the 24-bit mantissas, and a normalise-and-round stage that takes exactly one round-to-nearest-even decision at the final leading-one position (the round position is chosen from the sum's bit length BEFORE any shift, so there is no double rounding) plus a sticky bit. An operand more than 25 positions down the shifter contributes only a sticky bit, which is exact for round-to-nearest: a representable tie needs the distance to be exactly 24, so it is always inside the shifter. result=the binary32 pattern under round-to-nearest-even, with signed zero, exact subnormal output written as a code, and overflow to a correctly signed infinity. aux[0]=sticky, aux[1]=inexact, aux[2]=rounding incremented, aux[3]=infinity from overflow, aux[4]=zero result, aux[5]=subnormal result, aux[6]=operands swapped by the comparator, aux[7]=effective subtraction (operand sign flips included), aux[8]=0, aux[9]=infinity operand handled, aux[15:10]=0, aux[23:16]=alignment distance, aux[31:24]=0. fault=1 on a NaN input, on infinity-of-opposite-sign subtraction, or a nonzero c[31:1]. Documented deviation: no NaN payload is propagated (the class is reported as a fault instead), so this core is a finite-arithmetic adder, not a full IEEE quieting engine.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A full alignment/normalise/round adder settles inside one enabled beat: the 26-position shifter, the leading-one encoder and the tie-breaking round network are wired fan-in, so consecutive beats stream at interval 1 and the inexact and sticky flags come out beside the value. A soft core calls a library routine that unpacks both operands, branches on the exponent difference and runs a separate normalise loop, costing tens of instructions per sum.

Independent integer model: `step("fadd_s32", a, b, c, state)` in tools/fam_arith.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 116 distinct responses, 3 fault rows.
