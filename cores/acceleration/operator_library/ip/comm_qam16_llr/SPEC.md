# comm_qam16_llr

Max-log soft demapper for one Gray-labelled 16-QAM symbol per accepted beat. The in-phase coordinate is the signed byte a[7:0] and the quadrature coordinate is the signed byte a[15:8]; a[31:16] must be zero. Each axis carries the four levels -3S, -S, +S, +3S in that order, numbered k=0..3, with the symbol spacing S=b[2:0] in 1..7 and b[31:3] zero; level k emits the two Gray bits k^(k>>1), so bit 1 says which half of the axis and bit 0 says inner or outer. A rectangular constellation separates per axis under max-log MAP, so LLR(bit) = (smallest axis distance |coordinate-level| over the levels with bit=1) - (smallest over bit=0): positive means bit 0 is nearer. Both raw LLRs are multiples of S at most, so each is scaled by the receiver LLR gain 2^c[2:0] (0..7) and saturated to a signed byte; c[31:3] must be zero. result[7:0]=LLR of I bit 0, result[15:8]=LLR of I bit 1, result[23:16]=LLR of Q bit 0, result[31:24]=LLR of Q bit 1, all signed. aux[3:0]=hard decisions in the same order (1 when the raw, unscaled LLR is negative, a tie decides 0), aux[5:4]=index of the nearest level on I with the lowest index on a tie, aux[7:6]=same on Q, aux[10:8]=the gain exponent, aux[11+k]=LLR k saturated the signed byte, aux[15]=over-range alarm: |I| or |Q| exceeds 7S, aux[24:16]=Manhattan distance to the nearest constellation point (both axis contributions added), aux[27:25]=S, aux[31:28]=0. fault=1 when any LLR saturated or the over-range alarm fired (the full response is still reported) or on a malformed beat, which returns result=aux=0.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 4. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Eight absolute differences and six 8-bit minima retire a full 4-bit soft symbol in one enabled beat. The exact max-log MAP form needs 16 squared Euclidean distances and 16 min updates, so a soft core looping over a constellation cannot hold a symbol rate at all.

Independent integer model: `step("comm_qam16_llr", a, b, c, state)` in tools/fam_comm.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 115 distinct responses, 86 fault rows.
