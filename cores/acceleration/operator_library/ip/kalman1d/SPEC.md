# kalman1d

Steady-state (fixed-gain) scalar Kalman filter, one update per accepted beat. The state and the measurement are signed 12-bit words; the prediction model is the identity plus no input, so predict leaves x and only the update moves it. The gain is the precomputed steady-state value K/4096 held in state, which keeps the whole cone to one 12x12 product: r = z - x, correction = round_half_up(K*r / 4096), x := clamp12(x + correction). Variance bookkeeping is the innovation-scale EWMA V := clamp12u(V + ((|r| - V) >>> 3)), which is the quantity the optional innovation gate uses. a[11:0]=z signed, a[31:12] must be zero. b[11:0]=the gain K (1..2047, i.e. a steady-state gain below 1/2) read only on a restart beat, b[31:12] must be zero. c[3:0]=G the gate exponent, c[29]=1 enables the gate, c[30]=1 makes this a predict-only beat that consumes the measurement as nothing, c[31]=1 is the restart/config beat which loads K, zeroes x and V and clears the counters. c[28:4] must be zero. A restart with K=0 or K>2047 is rejected (fault, state kept and unconfigured), and a normal beat before any successful restart faults with result=aux=0 and state kept. The gate rejects a measurement when |r| > V + (V>>>G) + 1: x, V and the EWMA are then held and the beat faults. result = x after the beat, sign-extended to 32 bits. aux[12:0]=r (13-bit two-complement field), aux[24:13]=V, aux[25]=x clamped, aux[26]=gate rejected, aux[27]=predict only, aux[28]=V clamped, aux[29]=restart applied, aux[31:30]=0. State: x state[11:0] signed, K state[23:12], V state[35:24], configured state[36], saturating gate-reject count state[44:37], saturating update count state[52:45], saturating clamp count state[60:53].

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: One product and two shift-adds close the steady-state update on the same enabled edge the sample arrives, so the estimate never waits on a multiply-accumulate loop or a floating divide the way the textbook time-varying gain recursion does.

Independent integer model: `step("kalman1d", a, b, c, state)` in tools/fam_sensing.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 121 distinct responses, 16 fault rows.
