# ca_correlator

Cell-averaging CFAR detector step over a 16-cell sliding reference window, four unsigned 8-bit magnitude cells entering per accepted beat (a[7:0] first, a[31:24] last) and the decision taken on the window as held before the slide. The noise sum is the masked adder tree over state[127:0], cell i at state[8i+7:8i] with cell 0 the oldest; the 16-bit reference mask is c[19:4] and guard cells are simply excluded from it, so the divide by the cell count N is a shift and N must be a power of two. c[3:0]=the cell under test index (0..15), c[22:20]=the attenuation shift AT so threshold = mean + (mean>>>AT) + offset, c[30:23] must be zero. b[7:0]=the noise-floor offset, b[31:8] must be zero. c[31]=1 clears the window and every counter before this beat. A mask whose popcount is not in {2,4,8,16}, or that selects the cell under test itself, is an invalid guard pattern: no decision is taken, no hit or miss is counted, the beat faults, and the window still slides. A hit needs cell[cut] strictly above the threshold. result[7:0]=the cell under test, result[15:8]=mean noise level, result[16]=hit, result[17]=miss, result[18]=invalid guard pattern, result[19]=restart applied, result[31:20]=the masked noise sum. aux[12:0]=threshold, aux[13]=N was not a power of two, aux[14]=the mask selected the cell under test, aux[15]=restart applied, aux[19:16]=log2(N), aux[23:20]=saturating invalid-pattern count [3:0], aux[31:24]=saturating beat count. State: window state[127:0], saturating hit count state[135:128], saturating miss count state[143:136], saturating invalid-pattern count state[151:144], saturating beat count state[159:152].

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 4. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Four cells are appended and a whole 16-cell masked average, threshold and hit decision settle in one enabled edge through an adder tree, while a CPU CFAR loop re-sums the window and divides by N for every cell it touches.

Independent integer model: `step("ca_correlator", a, b, c, state)` in tools/fam_sensing.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 127 distinct responses, 68 fault rows.
