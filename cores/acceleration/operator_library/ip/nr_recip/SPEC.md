# nr_recip

Newton-Raphson reciprocal of a normalised 12-bit mantissa. Seed beat (c[31]=1) takes D=a[11:0] with 2049<=D<=4095 (x=D*2^-12 in (1/2,1)), loads E=D-3072 (so x=0.75+E*2^-12) and the seed V from the derived 64-bin ROM addressed by D>>6, and a[12] selects a negated result. Beats 1..3 apply V <- V + round((6144*tq + V*tq)/2^(24-k)) with tq=T>>k, k=7,3,1 and T=2^24-D*Y the exact residual of Y=6144+V (each beat is the Newton step Y <- Y*(2-x*Y) written in fixed point, so the error squares every beat). Beat 4 is an exact fix-up that recomputes T and adds (2T>=D) ? 1 : (2T<=-D) ? -1 : 0, which is the correctly rounded result because |T|<D there. A later beat with c[31]=0 once the phase counter is idle repeats the converged answer. Every correction beat forms the two products E*V and V*tq with one explicit 12-bit signed shift-add recode (12 conditional partial-product adds, sign-magnitude, no Verilog `*` anywhere). result=signed round(2^12/x)=signed round(2^24/D) (LSB 2^-12, magnitude 4097..8188 over the in-range D, proved by the exhaustive selftest sweep), aux[2:0]=phase counter, aux[3]=converged, aux[4]=sign applied, aux[5]=idle repeat, aux[9:6]=0, aux[15:10]=seed ROM bin (nonzero only on a seeded beat), aux[31:16]=low 16 bits of the residual T of the beat just run (zero on a seed or idle beat). fault=1 on D<=2048 (1/x would be 2 and does not fit the format) or when a beat's residual leaves the 12-bit slice window |T| < 2048*2^k (proved unreachable for in-range D by the exhaustive selftest sweep, kept as a range guard).

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Two shift-add recodes retire one quadratic-convergence correction per enabled beat: the residual 2^24-D*Y is exact in 25 bits so the loop needs no division, no compare-retry and no restoring branch, and the whole rounded reciprocal costs 5 beats. A soft core either calls a library divide or emulates the same iteration with several multiply-high instructions and a branch per correction.

Independent integer model: `step("nr_recip", a, b, c, state)` in tools/fam_arith.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 122 distinct responses, 5 fault rows.
