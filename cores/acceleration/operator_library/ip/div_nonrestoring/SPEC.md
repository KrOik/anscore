# div_nonrestoring

Non-restoring signed 32/32 integer divide, one bit-slice per accepted beat. Seed beat (c[31]=1) takes n=a signed and d=b signed, stores |d| (34 bits), |n| (32 bits), the sign XOR, a cleared 35-bit signed partial remainder and a cleared 32-bit magnitude quotient, and reports a zero-count state; beats 1..32 shift in one dividend bit (MSB first) and apply R <- 2R+bit-|d| when R was non-negative or R <- 2R+bit+|d| when it was negative, appending q=1 exactly when the new R is non-negative (that sign test is the quotient bit, so there is no restore pass inside the loop); beat 33 conditionally restores R <- R+|d| only when R is negative, leaving the quotient correct as it stands. Later beats with c[31]=0 once the counter has reached 33 repeat the converged answer. result=the truncated signed quotient (magnitude built from |n| and |d|, sign = sign XOR, so -7/2=-3 and -7%-2 is the C-truncated quotient, not floored); during the loop the same field carries the running quotient. aux[5:0]=slices done (33 means the restore beat has run), aux[6]=converged, aux[7]=sign applied to the quotient, aux[8]=restore taken, aux[9]=divisor magnitude is 2^31 (d=-2^31), aux[10]=dividend bit shifted in this beat, aux[31:11]=low 21 bits of the current partial remainder. fault=1 on d=0 (divide by zero) or on the single overflowing pair n=-2^31, d=-1.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: One division bit per enabled beat in a 35-bit signed slice: the quotient bit is the sign of the new remainder, so there is no restore branch and no multiply-estimate retry, and the width grows by widening the counter, not by rewriting the algorithm. A soft processor's 32-bit divide is either a fixed-cost multi-cycle unit or several hundred instructions of shift-subtract.

Independent integer model: `step("div_nonrestoring", a, b, c, state)` in tools/fam_arith.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 121 distinct responses, 3 fault rows.
