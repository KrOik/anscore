# tab_probe3_cuckoo

Three-probe cuckoo search over an eight-slot table held in the 256-bit state register: slot s occupies state bits [32s+31 : 32s] (the lowest word is slot 0), bit 31 of a slot = valid, bits [23:16] = stored tag, bits [15:0] = stored key, bits [30:24] = 0. No table image is generated: the table is loaded by config beats, which are the beats with c[31] = 1. Probe functions are shifts and xors only, h0 = key[2:0], h1 = (key>>3 ^ key>>6 ^ key>>9 ^ key>>12) & 7, h2 = (key>>1 ^ key>>4 ^ key>>7 ^ key>>10 ^ key>>13 ^ key>>15) & 7, tried in that order. Control: c[31] = 1 and c[30] = 0 inserts key a[15:0] with tag b[7:0]; if the key already sits in one of its three probes the beat is an in-place tag refresh, otherwise the key is placed in the first empty probe in probe order; c[31] = 1 with c[30] = 1 is the restart beat and empties the whole table (result = aux = 0); c[31] = 0 is a lookup of key a[15:0] with no state change and b ignored. result[15:0] = the search key (echoed on every non-faulting beat), result[23:16] = the tag of the matching slot for a lookup or the tag just stored for an insert and 0 on a lookup miss, result[25:24] = the probe position that answered, 1..3, 0 for a miss. aux[2:0]/[5:3]/[8:6] = h0/h1/h2, aux[10:9] = how many of the three probes were empty, aux[13:11] = how many held a foreign key, aux[20:17] = valid slots in the whole table before this beat. Fault rules, both of which leave state untouched: an insert whose three probes are all occupied by foreign keys is a full collision, and a key wider than the 16-bit search field (a[31:16] != 0) is illegal; either way result = aux = 0.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A software three-probe search is three dependent loads, compares and a branch chain; this issues all three probe reads, the foreign/empty accounting and the population count from fabric LUTs and the state word in one enabled beat, with no multiply and no memory port.

Independent integer model: `step("tab_probe3_cuckoo", a, b, c, state)` in tools/fam_table.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 108 distinct responses, 9 fault rows.
