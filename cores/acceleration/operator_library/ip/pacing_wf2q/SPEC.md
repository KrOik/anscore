# pacing_wf2q

One accepted beat runs a complete deficit/virtual-time round for four flows, the work a scheduler loop does one flow per iteration with a branch per decision. Flow L state: a 16-bit deficit D_L at state[16*L+15 : 16*L], a saturating service count at state[64+8*L +: 8] and a saturating backlog age at state[96+8*L +: 8]. Inputs: b[15:0] holds the four 4-bit weights w0..w3, a[15:0] the four head-packet size classes n0..n3 in 64-byte units, a[19:16] the four backlogged bits. c[31]=1 starts a new flow set (all four deficits, counters and ages go to zero before the round); c[23:16] is the starvation age threshold, 0 disables it. Per flow the round adds the weight-scaled quantum w*64 to the deficit, clamping at 65535 instead of wrapping, then serves the head packet iff the deficit covers n*64, paying it back and clearing the age, or carries the deficit and ages the flow. Serving is a decision, not a branch: the beat serves every flow that can pay, then a priority pick over the backlogged flows reports the least remaining deficit, ties going to the lowest flow index, which is the flow a deficit-round-robin engine transmits next. result[1:0]=winner, result[2]=a flow was backlogged, result[6:3]=served mask, result[10:7]=starved mask, result[14:11]=idle mask, result[15]=two flows tied on the minimum, result[19:16]=winner weight, result[21:20]=oldest backlogged flow, result[22]=sticky starvation, result[23]=sticky saturation, result[24]=restart echo, result[25]=a backlogged flow went unserved, result[28:26]=flows served, result[29]=the same flow won this round and the previous one, result[31:30]=previous round winner. aux[7:0]=rounds accepted, aux[23:8]=winner deficit after the round (0xffff when no flow was backlogged), aux[24]=a deficit or counter clamped this round, aux[25]=a flow crossed the age threshold this round, aux[26]=tie, aux[27]=a flow backlogged now was also served last round, aux[31:28]=aged mask. Fault rules: a clamped deficit or counter, and a backlogged flow reaching the age threshold, which means the pacing law stopped being fair; c[30:24] non-zero is malformed and gives result=aux=0 with the state kept.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 4. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A weighted scheduler in software walks a queue list, divides the packet size by the flow weight and re-sorts a heap; this advances four flows' deficits, decides all four transmissions, finds the minimum with a priority pick and updates the age and starvation masks in one enabled beat, with no divide anywhere.

Independent integer model: `step("pacing_wf2q", a, b, c, state)` in tools/fam_netio.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 123 distinct responses, 19 fault rows.
