# comm_nrzi_fmr32

NRZI (FMR) line-code transform for a 32-bit slice of the serial stream with transition-density and clock-lock accounting. Bit 0 of every word is the earliest in time. c[30]=0 decodes: result=data with data[k]=chan[k]^chan[k-1] and chan[-1]=state[0]. c[30]=1 encodes: result=channel level with chan[k]=chan[k-1]^data[k] and the same reference, so in both directions the data-domain word is the transition map and the same watchdogs apply to a transmit stream. c[31]=1 restarts first: the reference level becomes 0 and the run and total counters clear, then this beat is processed. c[29:1] must be zero. Limits come from b: b[5:0]=maximum transitions per beat (0 disables), b[11:6]=minimum transitions per beat (0 disables; a minimum above 32 can never be met so it always alarms), b[19:12]=maximum transition-free bits measured over beat boundaries (0 disables), b[31:20] must be zero. result[31:0]=the transformed word. aux[5:0]=transitions this beat, aux[13:6]=the transition-free run leaving this beat (saturating), aux[21:14]=the run that ends at this beat's first transition, i.e. the carried run plus this beat's leading data zeros (saturating), aux[22]=this beat had no transition, aux[23]=a limit was violated, aux[31:24]=transitions folded since the last restart (saturating). fault=1 on any violated limit (the response is still reported and state still advances) or on a malformed beat, which returns result=aux=0 and leaves state untouched. State: reference level = state[0], carried run = state[8:1], transitions total = state[31:24]. A run that starts and ends strictly inside one beat is only caught by the minimum-transition check.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 32. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A 32-bit prefix-XOR net and a 32-bit differential net replace the per-bit loop a soft core runs for the same slice, and the density, gap and lock alarms are produced in the same beat, so the line-code check costs no extra pass over the data.

Independent integer model: `step("comm_nrzi_fmr32", a, b, c, state)` in tools/fam_comm.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 115 distinct responses, 34 fault rows.
