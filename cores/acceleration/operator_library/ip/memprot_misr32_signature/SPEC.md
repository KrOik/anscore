# memprot_misr32_signature

Stateful 32-bit multiple-input signature register. One 32-bit data word per accepted beat is added in GF(2) after one multiply by x modulo the primitive polynomial P(x)=x^32+x^7+x^5+x^3+x^2+x+1, i.e. signature = ((state[31:0]<<1) & 32'hFFFFFFFF) ^ a ^ (state[31] ? 32'h000000AF : 32'h00000000). State: signature=state[31:0], folded beat count=state[63:32] (saturating at 65535), pass-start signature=state[95:64], never-toggled channel vector=state[99:96], zero-state latch=state[100]. Restart beat (c[31]=1) loads the seed from a[31:0] without folding it, sets the pass-start signature to that seed, clears the beat count and sets the never-toggled vector to 4'hF; the beat still runs the golden compare below. Data beat (c[31]=0) folds a[31:0] and clears never-toggled bit k once byte channel k of a has been non-zero (k=0 is a[7:0]). Golden compare: c[15:0] = mask of bits that must match, b[31:0] = golden signature, compare enabled when c[15:0]!=0, c[30:16] ignored. result = the 32-bit signature after this beat (the seed itself on a restart beat). aux[5:0] = number of the 32 signature bits that changed this beat (0..32), aux[9:6] = byte channel activity vector of a with channel 0 at bit 6, aux[10] = signature unchanged this beat, aux[11] = signature wrapped back onto the pass-start seed with at least one beat folded, aux[12] = fewer than 16 bits changed (weakly mixing beat), aux[13] = signature is zero, aux[14] = golden compare enabled, aux[15] = golden compare passed, aux[16] = some channel has still never toggled since the restart, aux[20:17] = never-toggled channel vector, aux[21] = zero signature latched since the restart, aux[31:22]=0. fault = the resulting signature is zero (indistinguishable from an un-initialised MISR) OR the golden compare is enabled and mismatched.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 32. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: One beat compresses a 32-bit bus word into a signature that a scalar core needs a shift, a conditional XOR and an accumulate per word, and the channel-activity flags prove every DUT output actually reached the compactor.

Independent integer model: `step("memprot_misr32_signature", a, b, c, state)` in tools/fam_memprot.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 128 distinct responses, 3 fault rows.
