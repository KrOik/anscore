# qinq_walk

One stacked-VLAN walk per accepted beat over three packed tag slots: slot k is TPID = word[15:0] and TCI = word[31:16] of a, b, c in order, so a, b, c carry the 12 bytes that follow an Ethernet MAC pair. TPID classification is parallel over all three slots: 0x8100 = 1 (C-tag), 0x88A8 = 2 (S-tag), 0x9100 = 3 (legacy provider Q-tag), anything else = 0 (a non-VLAN EtherType or length). The walk consumes leading slots whose class is non-zero and stops at the first class-0 slot, which is the terminating EtherType. result[11:0] = outer VID (the slot-0 TCI VID when the chain is non-empty, else 0), result[23:12] = inner VID (the deepest consumed slot), result[26:24] = depth 0..3, result[27] = untagged, result[28] = QinQ (depth >= 2), result[29] = outer slot is an S-tag, result[30] = inner slot is a C-tag, result[31] = exactly one C-tag. aux[5:0] = the classification map (2 bits per slot, slot 0 low), aux[6] = depth budget exceeded, aux[7] = a consumed slot used the reserved VID 0xFFF, aux[8] = outer slot is a null/priority tag (VID 0), aux[9] = inner slot is a null tag, aux[10] = outer DEI, aux[11] = inner DEI, aux[31:16] = the terminating EtherType (0 when the budget ran out first). Fault rules: all three slots carrying VLAN TPIDs means a fourth tag exists that this window cannot represent (depth budget exceeded) and the 12-bit VID 0xFFF is reserved by 802.1Q; either one raises fault while result/aux still report the parse. Stateless beat: c[31] is the third slot PCP bit, not a restart.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 3. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A QinQ parser in software is a loop with a branch per tag and a switch on TPID; here all three stacked slots are classified at once, the depth and the reserved-VID checks come out of the same priority chain, and a full double-tagged frame is parsed in a single enabled beat.

Independent integer model: `step("qinq_walk", a, b, c, state)` in tools/fam_netio.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 122 distinct responses, 48 fault rows.
