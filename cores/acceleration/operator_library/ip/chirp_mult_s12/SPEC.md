# chirp_mult_s12

Bluestein chirp multiply: reconstructs the full-plane chirp value from a first-quadrant (cos,sin) magnitude pair and a quadrant code -- one swap and two sign XORs, no divide -- then multiplies the sample by it and requantises. a[11:0]=x.re, a[23:12]=x.im signed 12; b[11:0]=cos, b[23:12]=sin signed Q1.10 magnitudes as stored in a quarter-period table; c[3:0]=L (log2 N, 2..12, so the quadrant is e>>(L-2)), c[5:4]=quadrant q, c[6]=conjugate (the second chirp of a Bluestein pair, or the inverse transform), c[31:7]=0; a[31:24]=b[31:24]=0. Any other pattern, or an L outside 2..12, is a malformed beat (result=aux=0, fault=1). Reconstruction follows twiddle_index16 exactly: swap=q[0], negate re=q[0]^q[1], negate im=q[1]; the conjugate flag negates the imaginary leg again. If a negation leaves the signed 12 slice window the lane is clamped and the reconstruction flag rises. The product is four MULT12X12 slices with round_half_up(...)>>10 requantise clamped to signed 12. result[11:0]=re, result[23:12]=im, result[24]=re clamped, result[25]=im clamped, result[26]=twiddle reconstruction clamped, result[27]=conjugate echo, result[29:28]=q, result[30]=the twiddle landed on an axis (a zero re or im leg, i.e. the product could have been a wire swap), result[31]=0. aux[11:0]=the signed 12 w.re fed to the slices, aux[23:12]=the signed 12 w.im fed to the slices, aux[27:24]=L, aux[31:28]=0. fault=1 on a malformed beat or any clamp.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 2. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Bluestein needs two chirp passes over the whole sequence and the chirp value for every index must first be unfolded from a quarter-period table: this core does the unfolding with one swap and two sign XORs (zero arithmetic) and spends its four slices only on the product, so a chirp leg costs no extra ROM, no trig and no second pass, at II=1.

Independent integer model: `step("chirp_mult_s12", a, b, c, state)` in tools/fam_fft.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 126 distinct responses, 16 fault rows.
