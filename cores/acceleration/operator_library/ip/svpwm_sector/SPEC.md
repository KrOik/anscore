# svpwm_sector

Space-vector modulation sector decode and 7-segment switching-state selection from three duty samples, one beat, stateless, no multiply. U=a[10:0], V=a[21:11], W=b[10:0] are signed Q10 counts; a[31:22], b[31:11] and c[30:12] must be zero (malformed beat: result=aux=0, fault=1). The projections X=V-W, Y=W-U, Z=U-V sum to zero, so their strict-positive sign triple idx=signX+2*signY+4*signZ has six live values (each a 60-degree wedge) and idx=0 only when U=V=W, which is a degenerate reference with no sector. sector, T1 and T2 come from a table derived in the family model from the volt-second solution: T1,T2 are two signed projections per idx, T1 for the vector at (sector-1)*60 degrees and T2 for the vector at sector*60 degrees, and the 7-segment pattern is V0,Va,Vb,V7,Vb,Va,V0 with Va,Vb those two switching states. c[31]=1 enables the modulation-index supervision and c[11:0]=limit L (the inscribed-circle value at full scale is round(1024*sqrt3)=1774); fault=1 when enabled and T1+T2 > L, or when the reference is degenerate. result[11:0]=T1, result[23:12]=T2, result[26:24]=Va, result[29:27]=Vb, result[30]=degenerate, result[31]=over-modulation. aux[11:0]=L, aux[14:12]=sector, aux[17:15]=idx, aux[18]=check enabled, aux[31:19]=0.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Sector decode is six compares, a sign triple and two projections: a CPU does it with branches that reorder the switching pattern from cycle to cycle, while this emits Va, Vb and both working times in the same beat the duty samples arrive, so the SVM pattern is deterministic at the PWM edge.

Independent integer model: `step("svpwm_sector", a, b, c, state)` in tools/fam_motor.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 125 distinct responses, 8 fault rows.
