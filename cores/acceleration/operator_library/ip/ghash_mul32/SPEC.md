# ghash_mul32

GHASH multiply in GF(2^128) mod x^128 + x^7 + x^2 + x + 1 (NIST SP 800-38D section 6.3, Algorithm 1), eight beats per product: state[127:0] is the accumulator Z and state[255:128] is V, the multiplicand being halved. c[3]=0 is an install beat: b goes into V word 3-c[1:0] (most significant word first), r = b and x = 40000000 | (index << 8); with c[31]=1 the same beat also zeroes Z, which is the restart beat and sets x[31] as well, and a restart with c[1:0] nonzero is malformed. c[3]=1 is a multiply beat: the 32 bits of a are consumed most significant bit first and per bit the loop does if x_bit then Z ^= V, then V >>= 1 and, when the shifted-out bit was 1, V ^= E10000000000000000000000000000000 - the reflected form of the field relation x^128 = x^7 + x^2 + x + 1. Four multiply beats (index 0..3, high word of the multiplier first) finish the product. r = Z[31:0]; the full 128-bit product stays threaded through the state, where a GHASH stream XORs the next block into V and multiplies again, exactly as Algorithm 2 does. x = (index << 8) | number of set bits consumed and x[31]=1 marks the completing beat index 3. c[2] or c[30:4] nonzero is malformed: f=1 with r=x=0 and the state untouched, and a multiply beat with c[31] set is malformed too. No multiply anywhere: the field step is one shift and two conditional XORs.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A carry-less 128-bit field multiply that never touches the broken fabric multiplier: four beats fold 32 multiplier bits each through one shift-XOR halving chain, and both the accumulator and the halved multiplicand stay in fabric registers across the eight beats of a GHASH step.

Independent integer model: `step("ghash_mul32", a, b, c, state)` in tools/fam_crypto.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 127 distinct responses, 2 fault rows.
