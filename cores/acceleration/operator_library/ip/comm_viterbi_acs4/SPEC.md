# comm_viterbi_acs4

One trellis section of the (7,5) octal rate-1/2 K=3 convolutional code: a four-state add-compare-select step with runtime metric normalisation, per beat. With input u and register bits u1, u2 the two channel bits are c0=u^u1^u2 and c1=u^u2, the state is s=u1*2+u2 and the next state is u*2+u1, so a section ending at next state ns carried input u=ns[1] and came from one of the two predecessors 2*ns[0] and 2*ns[0]+1. The received pair is the signed 6-bit symbol set y0=a[5:0], y1=a[11:6] with a[31:12] zero, and channel bit b maps to the expected level +A for b=0 and -A for b=1 with A=b[2:0] and b[31:3] zero. c[30]=1 switches to hard-decision metrics, the number of the two channel bits that disagree with the sign of the matching symbol, and then A is irrelevant. c[29:1] must be zero. c[31]=1 restarts the trellis first - state 0 becomes the only reachable state with metric 0 and the offset clears - and this beat is then decoded normally. Each candidate is a predecessor metric plus its branch distance; a candidate from an unreachable predecessor is the ceiling 1023 and cannot win, a reachable sum above 1023 saturates to 1023 and raises fault, and ties keep predecessor 2*ns[0], so the kept predecessor index is the decision bit. The four kept metrics are normalised by subtracting the smallest reachable one and that amount is accumulated into a 12-bit offset which saturates at 4095 and raises fault, so the maximum-likelihood path distance is offset plus the smallest metric. result[8k+7:8k]=state k metric after normalisation, clipped to 8 bits. aux[3:0]=decision bits, aux[5:4]=lowest index of the best reachable states, aux[8:6]=reachable state count, aux[13:9]=best-to-second-best margin clipped to 31 (31 with fewer than two reachable states), aux[14]=an ACS pair tied, aux[15]=a metric saturated, aux[16]=the offset saturated, aux[17]=restart applied, aux[29:18]=offset, aux[31:30]=0. State: metrics state[9:0], state[19:10], state[29:20], state[39:30]; reachable mask state[43:40]; offset state[55:44]. A malformed beat returns result=aux=0 and leaves state untouched.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 4. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Four ACS units, the reachability gating, the saturation clamps and the metric normalisation all close in one enabled beat, which is the II=1 a soft processor cannot hold: the same section costs eight adds, four compares and a traceback store per symbol time.

Independent integer model: `step("comm_viterbi_acs4", a, b, c, state)` in tools/fam_comm.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 124 distinct responses, 8 fault rows.
