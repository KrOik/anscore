# stockham_addr

Stockham stage address generator: maps (L, s, j) of one butterfly group to the read/write indices of the next buffer, with bank-clash detection and the matching twiddle exponent, using mask/shift/add only - no multiplier, no divide, no bit-reversal pass. a[3:0]=L (log2 N, 2..12), a[7:4]=s, a[19:8]=j, a[31:20]=0; b[1:0]=mode (0=radix-2 pair with stride 2^s, s<L and j<N/2; 1=radix-4 leg set with legs base+k*2^s, s<L-1 and j<N/4; 2 and 3 are reserved and malformed), b[31:2]=0; c[3:0]=bank width exponent bw (operands live in 2^bw single-port banks, 0..15), c[31:4]=0. base=((j>>s)<<(s+1|s+2)) | (j & (2^s-1)), so the pairs and leg sets provably partition 0..N-1. Any other bit pattern or an out-of-range (L,s,j) is a malformed beat (result=aux=0, fault=1). mode 0: result[11:0]=src, result[23:12]=dst=src+2^s. mode 1: result[11:0] and result[23:12]=legs 0 and 1, aux[11:0] and aux[23:12]=legs 2 and 3. Shared layout: result[24]=bank clash (two operands land in the same bank, i.e. stride mod 2^bw == 0), result[25]=1 (valid beat), result[27:26]=mode, result[31:28]=s. aux[11:0]=twiddle exponent e=(j & (2^s-1))<<(L-s-1) in mode 0 and leg 2 in mode 1, aux[23:12]=2^s in mode 0 and leg 3 in mode 1, aux[27:24]=the low storage bits of the first position, aux[31:28]=bw. fault=1 on a malformed beat only.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 2. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A radix-4 stage needs four addresses per beat and the bank-granularity answer decides whether the coefficient memory can serve them; here the four indices, the stride and the clash flag come out of two masks and three shifts in one beat, so the scheduler never recomputes addresses in a software loop between stages, and one cone covers both radix 2 and radix 4.

Independent integer model: `step("stockham_addr", a, b, c, state)` in tools/fam_fft.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 124 distinct responses, 5 fault rows.
