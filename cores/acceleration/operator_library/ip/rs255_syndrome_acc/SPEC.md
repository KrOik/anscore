# rs255_syndrome_acc

Reed-Solomon syndrome accumulator over GF(256) with the published primitive polynomial x^8+x^4+x^3+x^2+1 = 0x11D and alpha = x. Four symbols per accepted beat, in stream order sym0=a[7:0] ... sym3=a[31:24], and b[2:0] says how many of them are live (0..4, for shortened blocks and tail chunks); b[31:3] must be zero. For each live symbol and each syndrome register i = 0..3 the fold is S_i <- mul(S_i, alpha^i) ^ sym, so after N symbols S_i = sum_k sym_k * alpha^(i*(N-1-k)), i.e. the received polynomial evaluated at alpha^i with the first-fed symbol as the highest power. Every field multiply is an unrolled xtime walk (0, 1, 2 and 3 doublings for i = 0,1,2,3), so the core contains no product and no ROM. c[31]=1 clears all four syndrome registers and the counters before folding this beat, and the block syndromes it replaces are kept for block-to-block comparison; c[30:0] must be zero. t=2: four syndromes correct two symbol errors and detect three, and S_0 is the whole-block XOR. result[8i+7:8i] = S_i. aux[3:0] = per-syndrome nonzero flags, aux[6:4] = count of nonzero syndromes (0..4), aux[7] = all syndromes zero (clean so far), aux[8] = a nonzero syndrome has ever appeared in this block (sticky), aux[9] = restart applied, aux[10] = the syndromes saved at the last restart boundary were all zero, aux[11] = this beat was partial (fewer than four symbols), aux[12] = the symbol count saturated, aux[15:13] = 0, aux[31:16] = symbols folded since the last restart (saturating at 65535, which raises fault). State: state[31:0] = the four syndrome bytes, state[47:32] = symbol count, state[48] = sticky-error latch, state[63:49] = 0, state[95:64] = the four symbols of this beat, state[127:96] = the syndrome bytes at the last restart boundary, state[255:128] = 0. A malformed beat returns result=aux=0, fault=1 and leaves state untouched.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 4. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: Four syndrome registers fold four symbols per enabled beat: 24 xtime doublings, 16 XORs and the whole Horner step retire in one LUT cone, which is the symbol rate a storage controller or DVB receiver needs and far more than a bit-serial software fold that costs a loop per symbol per syndrome.

Independent integer model: `step("rs255_syndrome_acc", a, b, c, state)` in tools/fam_fec.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 127 distinct responses, 2 fault rows.
