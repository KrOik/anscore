# tlb8_lookup

Eight-entry translation lookaside buffer with parallel tag match and permission check. State: entry k = state[(k*16) +: 16] holding vpn = e[15:8], ppn = e[7:4], perm = e[3:1] (bit1 read, bit2 write, bit3 execute) and valid = e[0]; configured = state[128], inserts = state[136:129], hits = state[144:137], misses = state[152:145], permission violations = state[160:153], lookups = state[168:161] (all counters saturate at 255). Flush/restart beat (c[31]=1) invalidates all eight entries, clears every counter and sets configured. Insert beat (c[31]=0, c[0]=1): slot = a[2:0], vpn = a[15:8], ppn = b[3:0], perm = b[6:4], marks the entry valid and takes the insert counter. Lookup beat (c[31]=0, c[0]=0): key vpn = a[7:0], requested permission = a[10:8]; every valid entry compares in parallel, the lowest-index matching entry is used, the lookup counter is always taken, a hit takes the hit counter and returns ppn and the entry permission, a miss takes the miss counter, and a translation whose requested permission bits are not a subset of the entry permission is a violation, takes the violation counter and does not translate. Fault causes: 1 = insert or lookup before configure, 2 = no entry matched (TLB miss), 3 = permission violation; a faulting beat gives result = 0, aux[3:0] = the cause, and only the counters named above move. Otherwise result: [2:0]=slot, [7:4]=ppn, [10:8]=entry perm, [11]=insert beat, [12]=translate hit, [13]=configured. aux: [11:4]=inserts, [19:12]=lookups, [27:20]=hits (on success) or misses (on fault), [31:28]=violations low nibble.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 8. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: All eight tag compares, the priority pick and the three-bit permission subset test run in one enabled beat, so a translation returns at II=1 with a fixed latency and the tag array infers into block RAM, whereas a software TLB walk is a serial compare loop with data-dependent branch latency that leaks the miss path.

Independent integer model: `step("tlb8_lookup", a, b, c, state)` in tools/fam_memsys.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 128 distinct responses, 62 fault rows.
