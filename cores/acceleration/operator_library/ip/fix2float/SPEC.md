# fix2float

Fixed Q31 -> IEEE-754 binary32 in one beat (latency 1, not stateful). The signed value is a*2^(e-31) with e=$signed(c[7:0]) a runtime binary-point offset and c[31:8] required zero. The network priority-encodes the magnitude (leading-zero count l, 32 for a zero input), normalises n=|a|<<l so bit 31 is the implicit one, forms the biased exponent field F=e-l+127, then rounds the 23-bit fraction round-to-nearest-even from the 8 discarded bits with the tie broken by the kept LSB, propagates a fraction carry into the exponent, and takes the subnormal path (right shift 9-F, RNE, sticky, 9<=9-F<=32 handled by 64-bit guard masks, larger shifts collapse to zero-with-sticky) when F<=0. Overflow to infinity needs the rounding carry because c[7:0] caps F at 254, and it is reported as a correctly signed infinity with a flag rather than a fault. result=the 32-bit binary32 pattern with round-to-nearest-even, signed zero preserved and signed underflow to subnormal or signed zero. aux[7:0]=c[7:0] echoed, aux[8]=rounding incremented, aux[9]=sticky (information discarded), aux[10]=subnormal/underflow path taken, aux[11]=overflowed to infinity, aux[12]=exact (nothing discarded), aux[13]=zero input, aux[14]=sign, aux[19:15]=0, aux[25:20]=leading-zero count, aux[31:26]=0. fault=1 only on a nonzero c[31:8] (malformed binary-point selector).

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: A 32-bit priority encoder, a barrel normaliser and a round-to-nearest-even fix-up settle in one enabled beat: the leading-one position is a wired OR-reduction, so the cost is independent of the magnitude. A CPU needs a clz instruction plus a shift, a mask and a conditional exponent increment per sample, and has no notion of a runtime binary point at all.

Independent integer model: `step("fix2float", a, b, c, state)` in tools/fam_arith.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 124 distinct responses, 5 fault rows.
