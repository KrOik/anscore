# sha1_round

SHA-1 compression round (FIPS 180-4 section 6.1.2) over five words in state, slot j = A,B,C,D,E at bits 32j..32j+31. c[5:0..6:0]=t is the round index and a is the schedule word W t, which the caller expands (W t = rotl1 of W t-16 ^ W t-14 ^ W t-8 ^ W t-3 for t above 15, per FIPS 180-4 section 6.1.2); b is unused because the round constant is decoded in the fabric from t: 5a827999 below 20, 6ed9eba1 below 40, 8f1bbcdc below 60 and ca62c1d6 from 60 on - the four published K words, so no constant table or port is needed. c[31]=1 with c[30]=0 loads the published IV 67452301 efcdab89 98badcfe 10325476 c3d2e1f0 into the window before the round, making that beat round 0 of a new message; c[31]=1 with c[30]=1 is a slot-load beat: it writes a into word c[2:0] (slot 5..7 or any of c[29:3] nonzero is malformed) and runs no round, answering r=a and x=C0000000|slot, which is how the caller chains block 1 from block 0. f=1 with r=x=0 and the window untouched when c[29:7] is nonzero, when t exceeds 79, or when c[30] is set without c[31]. The round is T = rotl(A,5) + f(B,C,D) + E + W + K with the published chf of FIPS 180-4 section 4: Ch(B,C,D) = (B and C) or (not B and D) for t below 20, Parity(B,C,D) for below 40, Maj(B,C,D) = (B and C) or (B and D) or (C and D) for below 60, and Parity again from 60, all built from XOR, AND, NOT and shift-or rotates plus modulo-2^32 adds, never a multiply. Then E takes D, D takes C, C takes rotl(B,30), B takes A and A takes T. r = new A, x = f(B,C,D).

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 1. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: The 80-round SHA-1 chain runs one round per beat with the K window decoded from the round counter, so legacy SHA-1 framing shares the same fabric as SHA-256 instead of a second core.

Independent integer model: `step("sha1_round", a, b, c, state)` in tools/fam_crypto.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 127 distinct responses, 2 fault rows.
