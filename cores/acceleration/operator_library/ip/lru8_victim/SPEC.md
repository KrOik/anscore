# lru8_victim

Age-matrix 8-way LRU victim selector, the hardware LRU used by set-associative caches and bank routers. State: recency row i = state[8*i +: 8] (bit j set means way i was used more recently than way j), number of ways W = state[75:72], configured = state[76], references accepted = state[84:77], victim queries = state[92:85]. Configure/restart beat (c[31]=1) takes W from c[3:0], which must be 1..8 (else cause 4, state untouched), initialises the matrix so way 0 is the least recently used and way W-1 the most recently used, and clears both counters. Op beat (c[31]=0): with c[0]=1 the beat is a reference to way a[2:0]; the referenced way becomes most recently used (its row is every valid way except itself), every other row has the referenced way cleared, invalid-way rows stay zero, and a reference count is taken; a reference to a way at or above W is cause 2 and changes nothing. With c[0]=0 the beat is a victim query that only counts a query. The victim is the lowest-index valid way whose masked row is all zero. Fault causes: 1 = reference before configure, 2 = reference to an invalid way, 4 = W outside 1..8 on a configure beat; a faulting beat gives result = 0 and aux[2:0] = the cause with the matrix and counters unchanged. Otherwise result: [2:0]=victim before, [5:3]=victim after, [8:6]=referenced way (0 on a query), [9]=reference beat, [10]=query beat, [14:11]=W after, [22:15]=XOR fold of the eight rows after, [26:23]=W before. aux: [3:0]=W after, [11:4]=references after, [19:12]=queries after, [22:20]=victim before, [23]=configured, [31:24]=row fold.

See [common interface](../../doc/INTERFACE.md). Latency: 1 enabled edge(s); II=1 when output ready. Independent lanes per accepted beat: 8. Only accepted transactions update state. Reset clears pending output and state, even while CE is zero.

Hardware advantage: An 8-way victim needs one XOR-reduction and one priority pick per way every lookup; this retires the reference update and both the before and after victim selects in a single enabled beat at II=1, whereas a scalar core pays an eight iteration shift-and-compare loop plus a second pass for the age-matrix update.

Independent integer model: `step("lru8_victim", a, b, c, state)` in tools/fam_memsys.py. Vector rows: 320, of which 128 run on the board. Board-set coverage: 113 distinct responses, 18 fault rows.
