Pre-implementation read-only external review fetched SciPy v1.16.2 and resolved its annotated tag to commit **b1296b9b4393e251511fe8fdd3e58c22a1124899**. The `_peak_widths` implementation searches outward from a peak to contour crossings and interpolates between adjacent samples: [pinned source](https://github.com/scipy/scipy/blob/b1296b9b4393e251511fe8fdd3e58c22a1124899/scipy/signal/_peak_finding_utils.pyx). The [BSD-3-Clause license](https://github.com/scipy/scipy/blob/b1296b9b4393e251511fe8fdd3e58c22a1124899/LICENSE.txt) was read. This design uses a supplied baseline and an exact fraction of the global peak, rather than SciPy's supplied prominence/bases; it is independently authored finite fixed-point RTL. No SciPy source, extension, installation, build process or script enters the package or its oracle. HTTPS read-only inspection was used because the available web search endpoint returned HTTP500.

Semantic comparison examined actual implementations, including `dsp/statistics/statistics_stream.sv` (window amplitude/power/RMS/earliest absolute peak), `common_scaffold/peripherals/pulse_measurement` (filtered digital pin high/low/period in clock counts), `frequency_counter` and `event_interval_recorder` (digital events/epochs), `sys_trigger_window` and `sys_capture_replay` (waveform storage/streaming), `dsp/correlation/correlation_stream.sv` (sliding template correlation/lag/argmax), `lockin4` (reference-synchronous boxcar I/Q integration), `stream_phase_unwrap`/`stream_atan2` (phase measurement), timing recovery (integer-SPS Gardner without interpolation), Farrow/ASRC (resampling), and exact rational polynomial interpolation (small-node forward polynomial evaluation). These do not extract baseline-relative fractional-height crossings around a selected waveform peak. Global semantic searches additionally covered constant-fraction, FWHM, pulse-height/area/shape, crossing interpolation, arrival-time and equivalent terms. This package adds that measurement service; it does not reproduce an existing peak-only or digital edge counter.
