# ADC code-density finite qualification

The single root-authorized invocation passed four isolated preparation children
and eleven HDL children: three syntax/elaboration checks, four compilations and
four simulations. QUALIFICATION.json records exact source/archive, raw stream,
vector, preparation, tool and compiled/executed image hashes. The four VVP images
remain at their original ignored .build paths; this bridge does not copy them.

STATUS.json is the post-execution status supplement. Frozen README.md,
manifest.json, STATUS.md and SOURCE_SEAL.json retain their pre-execution wording
because all executed input bytes remain unchanged. The copied root review and
review_history/ROOT_REVIEW_TRANSITION.json bind the review-to-approved-plan step.

Verification covers finite digital arithmetic and handshake/reset behavior. It
provides no synthesis, routed timing, board, PPA or physical ADC accuracy claim.
Uniform-occupancy excitation is assumed; empty bins are missing-code candidates.
