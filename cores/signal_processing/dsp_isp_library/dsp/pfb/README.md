# DSP-16 PFB channelizer (pfb_stream)

M-channel polyphase filter bank + FFT channelizer for small M
(M in {4,8,16}, P taps/branch, M*P<=256).  Critically sampled: M complex
input samples per frame produce one M-beat output burst (tids 0..M-1).
Serialized shared-multiplier compute; sustained rate is M samples per
T_frame = M + (3*M*P + 2*M) + 4*(M/2)*log2(M) + 1 cycles.  See SPEC.md for the
exact polyphase/FFT ordering, fixed-point and backpressure contract, and for
why one tap / one butterfly is spread over several cycles.

## Reproduce from repository root

```text
python cores/signal_processing/dsp_isp_library/dsp/pfb/models/model.py --self-test
python cores/signal_processing/dsp_isp_library/dsp/pfb/tests/test_pfb.py          # M8P8 full
python cores/signal_processing/dsp_isp_library/dsp/pfb/tests/test_pfb.py --quick  # + M4P8, M16P4
python cores/signal_processing/dsp_isp_library/dsp/pfb/tests/synthesize.py        # yosys synth_gowin
```

`rtl/pfb_coeffs.vh` is generated by `models/model.py --emit-vh` (prototype
Blackman-windowed LPF, Q1.17).  iverilog/yosys resolve `include` from the
working directory first — the test/synth flows regenerate the LUT into each
evidence directory, so non-default (M,P) runs cannot pick up stale taps.

## Evidence status

Simulation: cycle-exact vs bit-accurate oracle for M=8/P=8 (18k rows),
M=4/P=8, M=16/P=4; per-channel isolation 60.5 dB worst-case at M8P8;
mid-channel aliasing, per-channel gain, frame tagging, backpressure holds,
mid-compute reset, runtime illegal-config and static-parameter rejection,
fixture-mutation negatives.  Synthesis: LUT 4.7K-12.2K, FF 1.6K-5.6K,
4 DSP, 0 BRAM across the legal lattice.  No P&R or board claim.
