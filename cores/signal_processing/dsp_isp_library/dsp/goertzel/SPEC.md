# DSP13 shared Goertzel bank

Runtime 1..4 frequencies and block length N=1..256. Frequency f is cycles/input
in [0,0.5], including noninteger bins; host generates c=RNE(2*cos(2*pi*f)*65536),
signed19 Q3.16, constrained to [-131072,131072]. Quantized coefficient defines
the actual recurrence frequency. Input signed16. Per-index window unsigned16
Q1.15 in [0,32768], supplied atomically with coefficients and unsigned80 power
thresholds. Rectangular, symmetric Hann/Hamming generated by the model tool;
N=1 uses unity for all windows. Windowed x=RNE(input*w/32768).

s=windowed_x+RNE(c*s1/65536)-s2; states are signed40. State overflow saturates
and sets a sticky block error, never wraps silently. With |c|<=2 and N<=256,
the conservative endpoint bound including half-LSB recurrence errors is
(32768+0.5)*N*(N+1)/2 <2^31; signed40 has ample guard bits. Windowed inputs
are bounded by signed16 range. State clears at every block boundary.

Terminal P=s1*s1+s2*s2-RNE(c*s1/65536)*s2; this explicitly rounds the same
coefficient product used by the recurrence, so it may differ slightly from an
unrounded Goertzel power. Clamp negative P to zero and values exceeding unsigned80
to maximum, marking error; output detect=(P>=threshold). Power is unnormalized
sample-LSB squared. Host calibration uses sum(w) for coherent tone amplitude
and sum(w*w) for noise power; real-tone interior-bin peak-amplitude estimate is
2*sqrt(P)/sum(w), with DC/Nyquist endpoint factor 1. Finite real-tone leakage and
noninteger-bin cross terms are not removed by this scaling.

One signed48x48 iterative multiplier, 48 shift/add steps, shared across window,
recurrence and terminal power. No II1 claim. RTL reports one tagged power result
per configured frequency, in order, after the Nth input. All bins are emitted
before the next block accepts input. Output is stable while stalled. Exact
latency/rate are measured by cycle regression and documented with the delivery.

Configuration valid/ready accepts only at a clean block boundary with no pending
output or arithmetic. It blocks input while waiting and therefore MUST NOT be
asserted mid-block as a replacement for remaining samples: the host must finish
the current block first. Legal updates replace N/bin count/coefficients/windows/
thresholds atomically. Invalid parameters reject the whole request. cfg_done and
cfg_error pulse. Synchronous active-low reset aborts current block/output and
selects N=1, one DC bin, unity window, zero threshold. No finite-tail padding.
Blocks run continuously with per-block state clear; output bin index identifies
frequency and last marks the final configured bin. Error is repeated on remaining
bin outputs after detection and clears before the next block. No board/P&R claim.
