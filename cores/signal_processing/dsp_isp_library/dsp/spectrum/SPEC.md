# DSP-05 spectrum pre/post processing family

Four cooperating stream cores in `rtl/`: `window_mult` (windowing),
`mag_squared` (complex power), `block_accum` (block sum/mean) and
`peak_search` (block maximum search). They are independent cores sharing this
contract; typical spectrum chain order is
`window_mult -> FFT -> mag_squared -> block_accum/peak_search`.

## Data formats and bin ordering

- Real samples: signed16 Q1.15 (`window_mult`, `block_accum` input).
- Complex samples: one 32-bit beat, `s_tdata[15:0]=I`, `s_tdata[31:16]=Q`,
  both signed16 Q1.15 (`mag_squared` input). Interleaving is *not* used;
  one complex sample per transfer.
- Window coefficient: signed18 Q3.15, 1.0 = 32768, range [-4, 4).
- `mag_squared` output: unsigned32 integer power units `i*i+q*q`.
- `block_accum` record `m_tdata[47:0]` = `{sum[31:0] signed, mean[15:0]
  signed}`; sum is the raw integer sum, mean is signed16.
- `peak_search` record `m_tdata[47:0]` = `{index[15:0], magnitude[31:0]}`;
  input is unsigned32 bins.

Bin ordering: index n counts 0..N-1 in arrival order inside each block of
N = 2**log2n samples (log2n = 4..12, N = 16..4096, power of two only). The
first sample accepted after reset or an accepted legal config is n=0. There
is no frame/sync sideband; an external agent aligns block boundaries to the
DFT frame. For a natural-order DFT output, index n is bin n (n <= N/2 is the
non-negative frequency n*fs/N; n > N/2 aliases negative frequencies).
Blocks are implicit: every N accepted samples complete one block; partial
blocks are discarded on reset or accepted legal config.

## Windowing contract (`window_mult`)

Periodic (DFT-even) window form, n = 0..N-1, t = 2*pi*n/N:

| type | formula | quantized constants A0/A1/A2 (Q3.15) | coherent gain |
|---|---|---|---|
| 0 unity | w = 1 | 32768 / 0 / 0 | 1.0 |
| 1 hann | w = 0.50 - 0.50*cos t | 16384 / 16384 / 0 | 0.5 |
| 2 hamming | w = 0.54 - 0.46*cos t | 17695 / 15073 / 0 | 0.540009 |
| 3 blackman | w = 0.42 - 0.50*cos t + 0.08*cos 2t | 13763 / 16384 / 2621 | 0.420013 |
| 4 custom | w = table[n] | uploaded RAM | mean(table)/32768 |

Named windows are computed in hardware from one shared quarter-wave cosine
ROM: `T[i]=round(cos(2*pi*i/4096)*32768)`, i = 0..1024, signed18 Q3.15.
Index n maps to phase `p = n*4096/N` (exact for every power-of-two N) and
2*t uses `2p mod 4096`. Quadrant decode: table index `p[10] ? 1024-p[9:0] :
p[9:0]`, sign `p[11]^p[10]`. The coefficient is
`sat18(RNE(A0<<15 - A1*c1 + A2*c2, 2**15))` — a generated-LUT implementation;
no trigonometric unit and no per-N table storage. `models/gen_window.py`
documents the same quantization and emits upload tables; an uploaded table
generated by `gen_window_table(log2n, type)` reproduces the corresponding
internal window bit-exactly.

Custom mode (type 4) reads coefficients from an internal signed18 Q3.15 RAM
written through the `coe_tdata/coe_tvalid/coe_tready` port. Entries are
written in index order 0..N-1; the upload counter resets on reset and on any
accepted config. While a custom-mode table is incomplete (`up_count < N`)
the input is backpressured. Upload beats are only accepted while the output
slot and pipeline are empty and no config/sample transfer is presented;
surplus beats beyond N are backpressured (never an overflow wrap). RAM
contents are not reset; every used entry must be uploaded before streaming.

Output: `y[n] = sat16(RNE(x[n]*w[n mod N], 2**(15+shift)))` with signed
`scale_shift` = cfg_shift in [-8, 15]. Positive shift divides by 2**shift
with RNE; negative shift multiplies by 2**(-shift) and may saturate (clip
flag = m_tuser[0]). One rounding at the final step only; no intermediate
saturation.

Amplitude scaling contract: the coherent gain CG = mean(w)/32768 shrinks a
bin-centered tone's amplitude to A*CG. Amplitude correction to ~1/CG is
applied through `scale_shift`, which approximates 1/CG only by powers of
two (e.g. shift -1 gives x2 for CG=0.5). Exact residual correction (e.g.
hann exactly x2, hamming ~x1.8518, blackman ~x2.3809) must be completed in
a downstream multiply or in analysis software; `gen_window.py` reports the
measured CG per table for that purpose. The clip flag marks saturation
introduced by the correction, never by a correct window alone
(|w| <= 1.0001 for named windows).

## Complex power contract (`mag_squared`)

`power = sat_u32(RNE(i*i + q*q, 2**shift))`, shift = cfg_shift 0..15
(unsigned truncation-free RNE right shift). For signed16 inputs
`i*i+q*q <= 2**31`, so the unsigned32 saturation and the m_tuser[0] clip
flag are structurally unreachable; they are kept for contract uniformity.
The shift exists for FFT-chain scaling (block-floating power spectra).

## Block accumulation contract (`block_accum`)

Per complete block of N accepted signed16 samples emits one record
`{sum32, mean16}`. `mean = sat16(RNE(sum, N))`; the divider is the
power-of-two shift by log2n with ties-to-even rounding on signed sums
(negative half values go to the even integer: -1.5 -> -2, -0.5 -> 0).
sum needs at most 27 bits for N=4096 (32768*4096 = 2**27), stored in the
signed32 field; no sum saturation exists. |mean| <= 32768 so the clip flag
is structurally 0 and retained for uniformity.

## Peak search contract (`peak_search`)

Per complete block of N accepted unsigned32 bins emits one record
`{index16, magnitude32}` = position and value of the maximum. Ties resolve
to the earliest index (strictly-greater update). `m_tuser[0]` =
`!thr_en || magnitude >= threshold`; the record is always emitted —
threshold only marks the flag, it does not suppress output. With
thr_en=0 the flag is constant 1.

## Stream, config and reset contract (all cores)

Single `clk`, synchronous active-low `rst_n`. `tdata/tvalid/tready`;
transfer on rising edge with `tvalid && tready`; valid is independent of
ready; all output fields hold while `m_tvalid && !m_tready`.

Pipelined cores (`window_mult`, `mag_squared`) are global-stall pipelines:
`s_tready = advance && qualifiers` with `advance = !m_tvalid || m_tready`.
Steady II=1; `window_mult` presents output 4 clocks after the input
transfer edge (earliest output transfer on the 5th edge), `mag_squared`
3 clocks. `block_accum`/`peak_search` accept at II=1 and emit one record
the cycle after each block-closing sample; while a record is stalled the
input backpressures, so a stalled record costs up to N cycles of input
starvation if the sink never resumes (documented, not an error).

Atomic config handshake: `cfg_valid && cfg_ready` commits all fields at
once; `cfg_done` pulses and `cfg_error` pulses additionally on rejection.
`cfg_ready` requires an empty output slot and empty pipeline
(`block_accum`/`peak_search`: empty output slot), so a config never
straddles in-flight data. Any illegal field rejects the whole update and
preserves the active config and algorithm state. Legal ranges:

- `window_mult`: log2n 4..12, window 0..4, shift -8..15.
- `mag_squared`: shift 0..15.
- `block_accum`, `peak_search`: log2n 4..12; peak also thr_en 0..1,
  threshold unsigned32.

An accepted legal config clears sample index/count, partial accumulators,
pipeline validity and the coefficient-upload counter. Reset clears the
same state plus config defaults (`window_mult`: log2n=4/unity/shift 0;
`mag_squared`: shift 0; `block_accum`/`peak_search`: log2n=4, thr_en=0,
threshold=0). RAM contents are not reset but cannot become valid output.
In-flight samples are discarded; no in-flight transaction survives reset
or an accepted config. Priority on simultaneous requests: config over
sample input over coefficient upload.

## Limitations

- No frame-sync sideband; bin alignment is the integrator's responsibility.
- `scale_shift` approximates 1/CG by powers of two only; residual gain
  error vs exact coherent-gain correction is documented above.
- Cosine ROM resolution is 4096 phases; N is restricted to powers of two
  so every window phase is exact. Non-power-of-two blocks are rejected.
- `window_cos_rom.sv` is a generated file (`models/gen_window.py
  --emit-rom`); regenerate it rather than editing.
- Isolated-core synthesis only; no P&R, timing closure, wrapper, chain or
  board acceptance claimed.
