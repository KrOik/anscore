## ISP chain physical failure RESOLVED (window_probe bisection)

Isolated the ISP left-edge failure with `board/window_probe` and debug variant
exporting wrapper internals per raster position. Three distinct GW2A silicon
divergences, all fixed and verified on hardware:

1. **Input-store lookahead drift** — `raddr=input_count+1` held during replay
   gaps drifted the BSRAM read on silicon (safe in sim). Fix: present
   `input_count` while idle, `+1` only during the take cycle. Applied to
   `board/window_probe/window_probe.v`, `board/image_harness/image_harness.v`,
   `board/block_harness/block_harness.v`.
2. **`stream_window` px==0 history zeroing** — `if(px==0) history[..]<=0`
   competed with `history[..+K-2]<=column` on the same registers; on silicon
   the replicated-edge (pad) pixel never entered history -> lane0 = 0 on the
   left edge. The zeroing was redundant (px<K-1 never emits); removed.
3. **`stream_window_padded` row_mem BSRAM CE widening** — mapped to DPX9B
   with CEB = widened shared CE LUT and OCEB tied on; during output stalls
   the address register re-sampled an already-advanced ridx -> pairwise
   pixel swaps under stall>0. Fixed by `ram_style="registers"` on row_mem
   (and inner banks).

Verification trail:
- `wp_fix1..fix4` variants bisect each cause on board (fix1: x0 fixed;
  fix4: stall0 PASS; fix5: all 16 cases PASS incl stall7).
- Debug variant `wp_dbg_...134615` exported raw rd stream + internals
  confirming the padded wrapper was correct and the inner window ate the
  pad column.
- fix5 build `wp_fix5_8x8k3p1d8_20260925_155951_588728` — board PASS
  `artifacts/dsp_isp_20260925/window_probe_fix5_02/verdict.json`.
- Full CSC->morphology chain `image8_pad1_20260925_161002_566586`
  (sha256 e6dd806b..., 2844 LUT, 0 DSP, Fmax>=110 MHz @27MHz):
  PASS x16 cases x2 SRAM rounds —
  `artifacts/dsp_isp_20260925/isp_chain_fixed_01` and
  `isp_chain_fixed_02_reprogram`.
- `record_isphw_20260925.py` recorded INFRA-02 + ISP-05 ->
  生产集成验收通过; chains.ISP status -> physical pass.

Lesson for library rule: on GW2A/Yosys, never rely on a CE-gated BSRAM read
whose result must hold across stalls — use `ram_style="registers"` for small
cache RAMs or drive `re` continuously with the address held at the active row.
