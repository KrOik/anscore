## FFT ordering (contract)

Host loads 64 samples in **natural order** via `ld_addr`; the core stores them
bit-reversed internally. Readback via `rd_addr` is **natural order**
`X[0..63]`. Output equals `DFT(x)/64` in Q1.15 (per-stage `>>>1` scaling).
One butterfly per 4 `clk_en` beats; 768 `clk_en` beats total after `start`.

## 2026-09-24: FFT full-rate repair and fresh physical evidence

The historical resource/timing and PENDING board text above are retained as
baseline records. They do not establish current full-rate correctness.
Fresh -noalu synthesis and physical raw-bin tests found that the old FFT fails
at clk_en=1 / 27 MHz even though its nextpnr estimate passes. Constant vectors
pass, but tone and random-complex bins fail. A three-product area reduction,
LUT4-only mapping and balanced reduction alone also fail full-rate captures.
The three-product version passes at clk_en=1/16, supporting a timing/settling
problem without establishing the exact silicon/tool root cause.

The final repair combines balanced partial-product reduction with product
registers. Fetching b/twiddle before a lets the multiplication and recombination
use separate existing beats. Latency stays 768 enabled beats, no DSP is used,
and externally valid readout and original digests are preserved. Internal
busy-time RAM outputs intentionally differ from the original access order.

Fresh regression (`scripts/test_sigproc_fft_optimization.ps1 -OutputDir <new>`)
passes 128 vectors / 8192 complex bins, baseline control/valid-read comparison,
pause/reset/busy-time-request checks, raw UART board-harness simulation, all
four original unit digests and the complete legacy UART report.

Physical full-rate captures across two programming operations pass 87 + 86
complete frames / 11072 complex bins, all eight vectors, all 768-cycle counts.
Inputs include the four original vectors, complex extrema and seeded random
complex data. Raw `.sr`, annotations, decoded bytes and host verdicts are in
`artifacts/ip_optimization_20260924/fft64/board_pipelined/` from repository root.
These are 27 MHz checks, not measured maximum-frequency or leakage claims.

Isolated LUT1-4 4368 -> 5166; FF 2190 -> 2254; DSP/BSRAM 0/0. Raw-output top:
5857 LUT4, 2366 FF, zero DSP/BSRAM; post-route estimate 60.82 MHz. This is a
full-rate reliability repair with an area cost, not an area-saving result.
Legacy four-unit board integration PASSES six complete original UART reports:
`SIG4 M=F P=F`; FFT `53D1DDAF`, CIC `076987E4`, histogram `C4B4F3D5`, Otsu
`D97CE6D3`. The integrated image uses the original FFT clk_en=1/16 pacing;
full-rate evidence is from the separate raw-output image. Integrated resource
use is 14012 LUT4, 3910 FF, 0 DSP and 1 BSRAM, below the resource gates.
Evidence: `artifacts/ip_optimization_20260924/fft64/board_pipelined_legacy/`.
