three hand certificates, independent encoder round trips, fixed error/prefix
semantics, full-table freeze, and the arithmetic reset-prefix certificates.
It emits 38 actual byte-stream fixtures and their complete expected index
streams, three main lists, three reset lists, the complete four-index reset
recovery packet, SOURCE_SEAL.json and PREPARATION_RECEIPT.json. It does not
invoke a compiler or simulator. Existing preparation is never overwritten.

Every child has a 20-second process-tree limit. The first failure/timeout stops
the matrix; all later slots retain NOT_RUN. Taskkill /PID /T /F is used on a
timeout, with bounded pipe draining. There is no automatic retry, dynamic split,
relaxed comparison, regeneration of goldens, synthesis, PnR, STA, board action or
inherited regression. Exact raw stdout/stderr bytes are saved and hashed before
parsing. Parsing splits CRLF lines before full-match comparison. A single
immutable attempt directory prevents reruns and contains the exact source copy,
fixtures, command list and per-child receipt. `--check` is read-only and starts
no child process.

The testbench compares every actual output index, tag and held summary, including
all retired prefixes on malformed and count-limited packets. It checks source,
index and completion holds; no overlapping input/index/completion ownership;
fresh packet boundaries; scalar and stack bounds; current-generation dictionary
reads; decreasing prefix links; synchronous read-q service; and successful-packet
work/width/allocation maxima against the independent whole-word oracle. Every
successful continuous main packet checks the paper cycle equation in COST.md.

All 24 reset predicates and their owners are fixed in CASE_TABLE.json. No
predicate or owner is searched after HDL observations. An unreachable predicate
fails at a fixed 400000-cycle packet bound. Every abort checks the exact already
retired prefix, offers input throughout three reset-high cycles, then verifies
the entire hand-certified fresh four-index packet with a different first tag
and a successful summary. A DONE-held probe presents the actual next packet's
first byte before reset. All active FSM states are covered; FIRST/reset input
gating is covered by initial and per-probe reset-high offers.
